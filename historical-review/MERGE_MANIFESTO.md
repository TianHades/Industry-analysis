## 两层之间的交叉链接

- 每个 **skill** 的 A1 案例节 → 指向具体的案例档案（如：光伏案例 → `行业案例档案库/技术迭代型/光伏_完整案例.md`）
- 每个 **案例档案** 的 frontmatter `related_cases` → 引用了其他案例的关联关系
- **框架文档** 的 7.2 节类比速查表 → 按场景快速定位最佳历史案例
- **案例关联关系图** → Mermaid 依赖关系图涵盖所有案例
- **分析技能层 INDEX.md** → 完整的技能依赖图 + 推荐学习顺序

## 使用路径

### 路径 A：快速分析"XX行业现在怎么样？"

```
1. 打开 分析技能层/industry-stage-locator/SKILL.md
   → 用三阶段框架定位

2. 打开 分析技能层/historical-stage-benchmarking/SKILL.md
   → 用"像→不像→像"找到最相似历史案例

3. 打开对应的案例档案（如 行业案例档案库/周期制造型/煤炭_完整案例.md）
   → 查时间线、数据、转折点

4. 参考 行业对比示范/ 中的完整演示
   → 用对比模板填写你自己的分析
```

### 路径 B：系统性学习行业分析方法

```
1. 阅读 行业生命周期全景框架_蒸馏笔记.md 第零章
   → 理解五力模型、关键术语、全书核心问题

2. 按 分析技能层/INDEX.md 推荐学习顺序
   → industry-stage-locator → capacity-cycle-positioning → ... → industry-replay-methodology

3. 每学一个skill，到对应案例档案中验证
   → 如学习产能周期，打开 煤炭/造纸/铜/油轮 四个案例对比产能周期长度的差异

4. 看 行业对比示范/ 中的完整演示
   → 理解方法论如何落在具体行业上
```

### 路径 C：风险教育

```
1. 打开 行业案例档案库/周期制造型/农林牧渔_完整案例.md
   → "长期几乎无超额收益" — 不是所有行业都值得投资

2. 打开 行业案例档案库/品牌消费型/教育_完整案例.md
   → "政策可以一夜之间改变行业边界" — 有些风险无法通过分散化消除

3. 打开 行业案例档案库/周期制造型/建筑装饰_完整案例.md
   → "没有定价权的中游行业永远是被挤压的" — 产业链位置决定利润归属
```

## 协同示例

**场景**：用户问"光伏现在是不是底部区域？"

**执行流程**：

```
Step 1: industry-stage-locator
  → 判断：光伏处于"过渡期"（政策退坡但经济性增强）
  → 核心指标：LCOE vs 火电成本、全球装机增速、产能利用率

Step 2: historical-stage-benchmarking
  → 表面相似：光伏2018年"531新政"底部（自身历史）
  → 关键差异：当前产能过剩幅度 > 2018年，但需求增速也 > 2018年
  → 驱动力回归：出清型底部 + 需求增长 → 参考煤炭2016年、造纸2016年

Step 3: 案例档案
  → 查 煤炭_完整案例.md：从信号触发到股价拐点约6个月
  → 查 造纸_完整案例.md：集中度提升+龙头Alpha → 太阳纸业穿越周期
  → 查 光伏_完整案例.md：2018年531新政后4个月触底

Step 4: 对比示范
  → 参考 示范一_周期制造型_光伏vs煤炭造纸.md（已包含完整Part 0-6分析）

Step 5: 参考框架 6.3 底部信号表（7 项，含权重）与示范一
  → 底部信号触发 5.5/7 → "关注区间"
```
