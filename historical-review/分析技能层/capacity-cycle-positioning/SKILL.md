# 产能周期定位框架

## R — 原文 (Reading)

> 回顾过去20年，伴随着中国经济的腾飞，中国的能源材料与中游制造行业也逐步做大做强，这其中伴随着宏观周期的波动，结构转型的成长，也交织着产能周期的调整。
>
> — 申万宏源研究所，中篇前言

> 需求决定方向，供给决定弹性。过去30年中没有出现铜需求疲弱但价格上涨的阶段。市场经济下供给往往"矫枉过正"导致产品价格出现周期波动。
>
> — 申万宏源研究所，中篇各周期性行业复盘章

## I — 方法论骨架 (Interpretation)

产能周期是连接宏观经济和中观行业盈利的最核心变量。它回答一个根本问题：一个行业的供给端目前处于什么状态，这将如何影响企业未来的盈利弹性和方向。

**产能周期的四个阶段**：

**第一阶段：产能扩张**。需求旺盛、产品价格高企、行业盈利丰厚，刺激企业大量投资扩产。关键识别指标：资本性支出（CapEx）增速持续高于营收增速、在建工程/固定资产比率上升、行业ROE处于历史高位、新进入者增多。这个阶段盈利虽好，但正在为下一阶段的过剩埋下种子——"高盈利本身会通过刺激供给扩张来摧毁高盈利"。

**第二阶段：产能过剩**。前期扩产项目集中建成投产，新增供给集中释放，而此时需求增速往往已放缓（或遇到政策突变、外部冲击），供需严重错配。关键识别指标：产能利用率持续下降、产品价格趋势性下跌、行业库存水位快速上升、企业毛利率系统性收窄、行业集中度下降（价格战中大小企业一同受损）。这是全行业盈利最痛苦的阶段。

**第三阶段：产能出清**。持续亏损迫使高成本企业退出（减产、停产、破产、被收购），供给端开始收缩。关键识别指标：行业产量增速转负、中小企业连续亏损超过4-6个季度、行业集中度（CR5/CR10）开始回升、并购重组事件增多、龙头公司毛利率率先企稳。出清的速度取决于退出壁垒——重资产行业（如化工、水泥）出清慢，轻资产行业出清快。

**第四阶段：供需再平衡**。过剩产能基本消化，幸存者的产能利用率回升至合理水平，产品价格企稳回升，龙头公司盈利修复。关键识别指标：产能利用率回升至75-80%以上、产品价格从底部反弹且有成交量配合、行业库存降至正常水平、龙头公司ROE回到资本成本之上、行业集中度较出清前显著提升。这一阶段的特征是"活下来的公司比以前更强"——因为竞争对手少了，定价权回归。

**核心法则**：
- **"需求决定方向，供给决定弹性"**：需求变化决定行业景气是向上还是向下（方向问题），但供给端状态决定盈利变化的幅度（弹性问题）。产能紧张时，需求小幅增长就能带来暴利；产能严重过剩时，需求增长仅能消化库存，盈利几乎不动。
- **"供给矫枉过正"**：市场经济中供给端的调整几乎总是过度的——涨价时企业过度扩产（乐观偏差），跌价时企业过度退出（恐慌出清）。这种"过度"恰恰创造了周期中的投资机会：在过度扩产的狂热中保持警惕，在过度出清的绝望中寻找拐点。

## A1 — 书中的应用 (Past Application)

### 案例 1: 铜价三轮需求大周期——30年"需求铁律"的完整验证

- **问题**: 铜被称为"经济晴雨表"，但铜价究竟由供给端（矿山投产周期长达5-7年）还是需求端（全球工业活动）主导？投资者经常用"当年供需缺口"来判断铜价方向，这个方法可靠吗？
- **方法论的使用**: 复盘过去30年铜价三轮大周期——第一轮（2001-2007）：中国重工业化转型拉动铜需求，铜价从1339美元/吨涨至8615美元/吨（涨幅540%）；第二轮（2008-2011）：中国"四万亿"刺激需求，铜价涨至9895美元/吨（涨幅250%）；第三轮（2016-2018）：棚改货币化安置拉动地产链铜需求，铜价涨至7305美元/吨（涨幅57%）。作者还检验了一个关键假设：将25年的铜价方向与当年供需缺口对照，发现13年两者方向相反——在需求上升大周期中，即使当年供过于求，铜价依然上涨；在需求下行大周期中，即使当年供不应求，铜价依然疲弱。
- **结论**: "需求决定方向，供给决定弹性"在铜这一"最难增产"的金属上得到最有力的验证。铜矿投产周期长达5-7年（供给刚性极强），但决定铜价的核心变量仍然是需求周期而非供给。当年供需缺口的线性思维有超过一半的概率判断错方向——因为市场交易的是"未来的供需预期"而非"当前的供需现实"。涨幅逐轮递减（540%→250%→57%）背后是中国经济增长中枢下移带来的需求强度递减，进一步证明了需求才是主导变量。
- **结果**: 每一轮铜需求的上升周期都驱动了铜价大幅上涨，即使供给同步增加也无法阻挡。2008年全球金融危机期间，货币政策已极度宽松，但因缺乏真实需求支撑，铜价依然暴跌——"过去30年中没有出现铜需求疲弱但价格上涨的阶段"被完整验证。

### 案例 2: 光伏行业三轮产能过剩与出清——从"双反"到"531新政"的完整产能周期

- **问题**: 光伏行业在2004-2020年间经历了数次"暴涨暴跌"——为什么一个长期成长性如此确定的行业，股价和盈利的波动如此剧烈？
- **方法论的使用**: 用产能四阶段框架逐轮定位：(1)2005-2008年产能扩张期——西班牙高额补贴+全球装机需求爆发，多晶硅价格从100-200美元/千克（2006年）暴涨至500美元/千克（2008年），全行业疯狂扩产加杠杆；(2)2009-2012年第一轮产能过剩与出清——西班牙补贴退坡（装机骤减99%）+金融危机+前期扩产集中释放，多晶硅暴跌至60美元/千克，随后2012年欧美"双反"雪上加霜，无锡尚德、LDK、英利等龙头相继破产重组，完成第一轮残酷出清；(3)2013-2017年再平衡后第二波扩张——中国需求爆发+单晶技术迭代，隆基等龙头崛起；(4)2018年"531新政"再度触发过剩——补贴突然大幅收紧，产业链价格5个月跌超30%，但此次出清更快（仅4个月），因为海外需求（平价上网后经济性驱动）迅速接棒，行业进入"需求多元化+经济性驱动"的再平衡。
- **结论**: 光伏行业的16年完美演绎了产能周期的完整轮回，且每一轮的出清都催生了更强的龙头——隆基（2012 年上市）在后两轮周期中大幅跑赢行业指数（2005-2008 年首轮尚无上市股价可比）。关键规律是：政策驱动期的产能周期更剧烈（政策补贴可以瞬间创造需求也可以瞬间消灭需求），但一旦行业跨过平价临界点进入经济性驱动期，需求端的多元化会显著降低产能周期的振幅。
- **结果**: 光伏设备指数在每一轮出清的底部都孕育了后续数倍的大行情，但抄底的关键不是看价格跌了多少，而是确认"供给出清+需求多元化"的双重信号——531新政后仅4个月行业就触底反弹，因为低成本刺激了海外真实需求，产能出清和需求切换同时发生。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. **用户想判断一个周期性行业的景气位置** — 某行业（如有色、化工、造纸、光伏、生猪等）产品价格已大幅波动，用户想系统性判断当前处于产能周期的哪个阶段，以及盈利拐点可能何时到来。
2. **用户想判断"抄底"时机** — 某周期性行业已持续低迷较长时间，价格低位运行、企业大面积亏损，用户想知道是否到了可以左侧布局的阶段，需要识别产能出清的信号是否已足够充分。
3. **用户对新进入者涌入的行业感到担忧** — 某行业当前盈利丰厚、大量资本涌入扩产，用户担忧未来产能过剩，想判断当前处于"扩张期的早期"还是"接近过剩的临界点"。
4. **用户想比较两个行业的景气弹性** — 两个行业都受益于同一宏观驱动力（如基建投资），但用户想判断哪个行业的盈利弹性更大，需要分析两者的供给端状态差异。
5. **用户看到产品涨价想追入** — 某大宗商品或工业品价格正在上涨，用户想判断这是需求驱动的可持续上涨还是供给短期扰动，是否值得追入。

### 语言信号 (用户的话里出现这些就应激活)

- "XX行业产能过剩了吗？"
- "现在是周期底部还是顶部？"
- "什么时候可以抄底？"
- "这个行业现在在产能周期的什么位置？"
- "价格涨/跌了这么多，是供给端还是需求端的问题？"
- "XX行业还在出清吗？出清到什么阶段了？"
- "为什么需求明明在增长，这个行业的公司还是不赚钱？"

### 与相邻 skill 的区分

- 与 `industry-stage-locator` 的区别：Skill A 聚焦于产业生命周期（导入→成长→成熟→衰退），关注的是行业长期发展阶段的定位和对应的核心驱动力切换；本 skill 聚焦于产能周期（扩张→过剩→出清→再平衡），关注的是中短期供需格局变化和盈利周期性波动。两者互补——产业生命周期告诉你"这个行业现在是什么年纪"，产能周期告诉你"这个行业现在呼吸节奏如何"。
- 与 `bull-bear-signal-system` 的区别：Skill C 是宏观市场层面的大势研判（判断整个A股是牛是熊、行情性质如何），本 skill 是中观行业层面的景气定位（判断具体行业的供需格局和盈利拐点）。同一个宏观环境下，不同行业的产能周期位置可以完全不同。
- 与 `policy-driver-assessment` 的区别：Skill F 评估政策如何影响行业（补贴、牌照、税收等工具分析），本 skill 中政策只作为影响产能周期的变量之一——政策可以加速或打断产能周期的自然演进（如供给侧改革强制出清），但产能周期的内在逻辑（高盈利→扩产→过剩→出清）独立于政策存在。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行:

1. **需求方向判断 — 确认"方向"**
   - 分析目标行业的下游需求趋势：需求量/销量增速（近3-5年及当前趋势方向）、需求驱动因素拆解（宏观驱动？政策驱动？出口驱动？技术替代驱动？）、需求二阶导数（增速是在加速还是减速）。对于工业金属/大宗商品，需同步检查全球PMI、工业增加值等宏观需求指标。
   - 完成标准: 明确给出"需求扩张/需求稳定/需求收缩"的判断，并标注需求驱动力是"周期性"（随宏观波动）还是"结构性"（如平价上网后的内生增长），这决定了需求的可持续性。
   - 判停条件: 若行业下游需求过于分散（如通用化工品）或缺乏可靠的行业级需求数据，标记"需求数据不可靠"，后续结论需降低置信度。

2. **供给弹性评估 — 确认"弹性"**
   - 收集供给端数据：行业产能利用率（当前值及趋势，通常从行业协会或券商研报获取）、CapEx增速（过去3-5年全行业资本支出的变化方向和幅度）、在建工程/固定资产比率（判断供给释放的时间表和规模）、行业集中度（CR5/CR10当前值及变化趋势）、库存水位（绝对值和同比变化，区分产业链各环节库存）。
   - 完成标准: 给出"供给紧张/供给宽松/供给严重过剩"的判断。进一步计算：若需求增长X%，在当前供给状态下，产能利用率会如何变化？价格弹性大约多大？
   - 判停条件: 若行业存在大量"隐性产能"（如小煤矿、地条钢等不在官方统计中的产能），或行业数据严重不透明（如某些小金属品种），标记"供给数据不完全"，结论需注明数据局限。

3. **产能周期四阶段定位**
   - 将步骤1和步骤2的结论对照以下矩阵进行四阶段定位：
     - **产能扩张**: 需求旺盛+产能利用率高+CapEx增速显著高于营收增速+行业ROE高位+新进入者增多
     - **产能过剩**: 需求增速放缓+产能利用率趋势性下行+在建工程大量转固+产品价格下跌+行业毛利率收窄
     - **产能出清**: 需求走平或微增+产量增速转负+中小企业持续亏损+行业集中度回升+龙头毛利率率先企稳
     - **供需再平衡**: 需求企稳或恢复+产能利用率回升至正常水平+库存降至正常+产品价格企稳回升+龙头ROE回正
   - 完成标准: 给出明确的四阶段定位结论，并列出支撑该判断的3-5条核心证据。必须同时给出"阶段内位置"的判断——如"出清中段"还是"出清尾声"（这直接关系抄底时机）。
   - 判停条件: 若行业处于两阶段之间的过渡地带（如"扩张末期但也出现了过剩苗头"），应给出两个可能阶段及各自的概率估计，并列出后续决定走向的关键观察变量。不要强行归入单一阶段。

4. **跨行业/跨周期参照**
   - 寻找历史上处于类似产能周期位置的行业案例（如当前分析的行业类似2016年的水泥、或2019年的锂、或2011年的造纸），提取那个案例中产能周期演化的时间线和关键转折信号。
   - 完成标准: 找到至少1个高度可比的历史案例，说明"那个案例中从当前阶段到下一阶段用了多长时间、触发转折的关键事件是什么"。同时说明当前行业与那个案例的关键差异（"不像"的地方）。
   - 判停条件: 若找不到高相关性的历史案例（如该行业数据历史过短），则跳过此步，在结论中标注"缺乏历史参照"。

5. **综合结论与关键跟踪指标**
   - 汇总四个步骤，输出：(a)当前所处的产能周期阶段；(b)阶段内位置（早期/中段/尾声）；(c)预计切换至下一阶段的核心触发条件；(d)需要持续跟踪的3-5个先行指标及各自的"拐点阈值"（如"当产能利用率连续两个季度回升至75%以上，则确认进入再平衡阶段"）。
   - 完成标准: 用户拿到结论后，能够独立完成后续跟踪——知道该盯什么指标、指标到了什么水平该修正判断。清单式输出，每条含"如果X发生，则意味着Y"的逻辑。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **需求无弹性的行业**: 如殡葬、基础公用事业（水电煤气——非市场化定价部分）、某些必需品医疗服务。这些行业的需求几乎不受价格或经济周期影响，供给端变化对盈利的影响路径与标准产能周期模型完全不同。即使出现"供给过剩"，价格和盈利的调整机制也不按市场规律运行。
- **政府定价/深度行政干预的行业**: 如中国成品油（发改委定价）、部分公用事业（阶梯电价/水价由政府核定）、深度受"供给侧改革"行政命令管控的行业（2016年后的中国煤炭，煤价与国际油价相关性从70%降至25%）。这些行业的"产能过剩"和"出清"更多是政策意志而非市场的自发过程，本框架的指标可能发出错误的信号。特别警告：在行政干预强度大的行业，历史上有效的跨市场参考框架（如用国际煤价判断国内煤价）会系统性失效。
- **新兴、缺乏超过一个完整周期数据的行业**: 如刚起步的新材料、氢能、可控核聚变等。产能周期分析需要至少覆盖一个完整的"扩张→过剩→出清→再平衡"循环的数据（通常需要10年以上），否则无法判断当前所处位置是"周期高位"还是"趋势起点"。新行业的首次扩产——即使规模很大——未必会经历传统意义的过剩，因为它可能是在满足从零到一的真实需求。
- **科技服务业等轻资产行业**: 如软件、互联网平台、咨询等以人力资本为主的行业，没有传统意义上的"产能"概念（扩产不需要建设工厂、出清不需要处置固定资产）。这些行业的供需分析需要完全不同的框架。
- **供给几乎完全受自然条件约束的行业**: 如部分农产品（天气决定产量远超投资决定产量）、高端奢侈品（产能被人为限制以维持稀缺性）。产能周期模型的"扩产→过剩"逻辑在这些行业不成立。

### 作者在书中警告的失败模式

- **"当年供需缺口"不可靠**: 作者反复验证，当年供需缺口与价格方向没有一一对应关系——25年铜价数据中有13年两者背离。市场交易的是"未来的供需预期"而非"当前的供需现实"。在供给长周期行业（投产周期3-7年）中，判断需求处于上升期还是下降期，比计算当年的供需平衡表重要得多。
- **行政干预可能掩盖而非解决产能问题**: 煤炭行业在山西"先停后整"式资源整合中，短期产能收缩导致煤价暴涨，但整合后负债率不降反升、非整合区趁机扩产、新建产能几年后集中释放，最终产能过剩问题比整合前更严重。行政去产能改变的是供给的时间分布，不是总量。
- **高盈利是最危险的信号**: 在重资产周期行业中，"高盈利可持续"是最危险的假设——高盈利本身会通过刺激全行业扩产来摧毁高盈利。产能周期定位的核心不是看当期盈利有多好，而是看"当前的高盈利正在催生多少未来的供给"。

### 作者的盲点 / 时代局限

- **"碳中和"改变了传统产能周期的节奏**: 成书于2020年，未完全覆盖2021年后"双碳"政策对高耗能行业产能扩张的永久性约束。在碳排放约束下，某些行业的"产能扩张"阶段可能被人为压制——即使盈利再丰厚也无法扩产——这意味着传统产能周期的"扩张→过剩"节奏可能被拉长或永久改变，产能从"周期性"向"持续性紧张"漂移。
- **全球供应链重构的影响未纳入**: 后疫情时代的"近岸外包""友岸外包"和供应链安全考量正在改变全球产能布局的逻辑——过去是基于比较优势的全球分工（哪里成本低在哪里建产能），现在加入了地缘政治考量（哪里安全在哪里建产能）。这意味着某些行业的"全球产能过剩/紧缺"判断需要加入地缘政治维度，而书中的纯经济分析框架可能不完整。
- **ESG和投资者压力加速出清**: 书中讨论的产能出清主要通过市场亏损驱动，但近年ESG投资趋势和股东积极主义可能加速高污染/高碳行业的出清（投资者"用脚投票"、银行拒绝贷款），这种非经济驱动的出清在速度上可能远超历史经验。

### 容易混淆的邻近方法论

- **与产业生命周期框架混淆**: 产能周期（扩张→过剩→出清→再平衡）是3-8年的中周期波动，产业生命周期（导入→成长→成熟→衰退）是10-30年的长周期演化。一个行业在产业生命周期的"成长期"可能经历多轮产能周期（如光伏16年经历3轮完整产能周期）。两者不能互相替代。
- **与库存周期（基钦周期）混淆**: 库存周期是2-4年的短周期，关注产成品库存的波动。库存变化会放大或缓冲产能周期的价格波动（如"牛鞭效应"），但产能周期比库存周期更长、更根本——产能过剩不是"仓库里货太多"的问题，而是"工厂建太多了"的问题。
- **与商品期货的技术分析混淆**: 用技术面方法（如均线、MACD、RSI）判断大宗商品价格的买卖时机不属于本框架。本 skill 分析的是产能周期的基本面位置，它回答的是"价格应该在什么方向走"而不是"明天涨还是跌"。
