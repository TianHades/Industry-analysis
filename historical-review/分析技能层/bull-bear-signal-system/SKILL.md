# 牛熊切换信号体系

## R — 原文 (Reading)

> 2014年强美元环境中的"水牛"为日后贬值埋下伏笔……2016年下半年全球经济开始同步复苏，叠加中国供给侧改革，全球股市走出业绩牛。8月股市脱敏贸易协商不确定性。我们稳了，对手反而急了。
>
> — 申万宏源研究所，上篇"千磨万砺还坚劲"/上篇第9节

> 2017年最后验证了，基本面趋势一旦形成即很难证伪，龙头趋势未完。
>
> — 申万宏源研究所，后记"唯有时代，盛开着永不凋零"

## I — 方法论骨架 (Interpretation)

A股市场的上涨有两种截然不同的性质，分辨它们决定了你是搭上顺风车还是坐上过山车。

**水牛 vs 业绩牛的本质区别**：水牛由分母端驱动——流动性泛滥叠加风险偏好高涨，但企业盈利（分子端）没有改善甚至恶化。这种牛市的特征是估值单边扩张、小盘股和题材股领涨、杠杆资金和散户主导。它来得猛烈，但崩塌也猛烈，因为缺乏盈利这个"锚"。业绩牛由分子端驱动——企业盈利趋势性改善，估值扩张与盈利增长基本匹配。特征是龙头白马领涨、机构资金主导、上涨节奏更慢但更可持续。

**分辨的核心信号**：(1)看ROE——业绩牛的ROE趋势向上或至少企稳，水牛的ROE下行或低迷；(2)看PE扩张速度——水牛的PE涨幅远超盈利增速，业绩牛两者匹配；(3)看资金结构——水牛的特征是两融余额激增、新增散户账户暴增，业绩牛的特征是外资持续流入、机构仓位稳定提升；(4)看领涨品种——水牛中小盘和题材股领涨，业绩牛龙头白马领涨。

**戴维斯双击/双杀**：当盈利和估值同向变动时，产生乘数效应。双击发生在"盈利改善+估值低位"的组合——盈利拐点向上而市场尚未充分定价时，股价会有加速上涨。双杀发生在"盈利恶化+估值高位"的组合——盈利拐点向下而估值仍在高位时，股价会加速下跌。核心不是判断盈利好不好，而是判断盈利的"二阶导数"（趋势是改善还是恶化）与当前估值位置是否匹配。

**脱敏机制**：当同一类冲击反复出现，市场的反应逐次减弱，这就是脱敏。脱敏不是"完全不受影响"，而是边际影响递减。发生脱敏需同时满足三个条件：(1)冲击可预期（反复出现形成学习效应）；(2)对冲力量可信（政策工具箱充足且执行坚决）；(3)内因（基本面趋势、改革预期）强于外因。脱敏是判断市场底部和韧性的关键信号。

**趋势一旦形成难证伪**：基本面向好趋势确立后，市场会沿着趋势方向持续定价，中途的怀疑和回调往往被证明是买入机会。这不是说趋势不会结束，而是趋势的惯性往往超出多数人预期。

## A1 — 书中的应用 (Past Application)

### 案例 1: 2014-2015年水牛的兴起与崩塌

- **问题**: 2014年中国经济下行、通缩压力加剧，但央行转向宽松后A股大幅上涨。投资者面临核心困惑：这是一轮可持续的牛市，还是流动性催生的泡沫？
- **方法论的使用**: 用"水牛vs业绩牛"框架逐层检验——(1)分子端：工业企业利润增速持续下行，ROE未见改善；(2)分母端：央行PSL/SLF/降息密集落地，流动性极度宽松；(3)资金面：两融余额从4000亿飙升至2.27万亿，新增股票账户单周最高443.5万户；(4)领涨品种：创业板"互联网+"题材股领涨。四项指标全部指向"水牛"。
- **结论**: 这是一轮缺乏盈利支撑的水牛。作者回溯2005-2019年的规律——"基本面下行、仅靠流动性宽松驱动市场上涨最多不会超过一个季度"，2015年成为该规律唯一的反例，因杠杆放大了持续性，但也为更猛烈的崩塌埋下伏笔。
- **结果**: 2015年6月上证触及5178点后，清查配资引发杠杆踩踏，千股跌停，上证腰斩至2850点。水牛验证了"来得快去得也快"的基本规律，杠杆只是拉长了泡沫的寿命，没有改变泡沫的终局。

### 案例 2: 2019年A股对贸易摩擦的脱敏过程

- **问题**: 2018年中美贸易摩擦每次升级都引发A股大跌（3月中兴事件、6月关税升级、10月科技封锁），市场对贸易摩擦极度敏感。但到了2019年中，同样的关税威胁是否还会引发同样的暴跌？
- **方法论的使用**: 用"脱敏"框架分析——(1)冲击可预期：贸易谈判反反复复已持续一年半，市场逐渐形成学习效应；(2)对冲工具可信：易会满明确表态"准备了丰富的工具箱"，国内政策"以我为主"；(3)内因强于外因：科创板开板维稳预期+新中国成立70周年政策窗口+国内资本市场改革推进。
- **结论**: 三个条件同时满足，市场对贸易摩擦正在脱敏——"我们稳了，对手反而急了"。市场将从每次升级都大跌，过渡到低开后即消化，最终走出独立行情。
- **结果**: 2019年5月特朗普突然威胁加征关税后上证仍跌5.6%，但到了8月美方再次升级关税+人民币破"7"时，A股仅低开高走即消化冲击。此后特朗普多次反复，市场反应越来越弱，9月A股几乎收复前期全部跌幅。脱敏判断被市场完整验证。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. **用户对市场方向感到困惑** — 市场大涨但用户不确定这是可持续的牛市还是一轮流动性驱动的反弹，想系统性地判断当前上涨的性质。
2. **用户担忧行情持续性** — 市场已上涨一段时间，用户持有仓位但不确定是否应该继续持有，想判断行情是处于戴维斯双击的早期还是末期。
3. **用户对市场"反常"反应不解** — 重大利空出现但市场没有下跌甚至上涨，用户想理解这是脱敏信号还是"市场疯了"。
4. **用户想判断拐点** — 市场已下跌较多，用户想判断是否到了抄底时机，需要结构化地评估各种见底信号是否已出现。
5. **用户看到趋势想追入** — 某个方向（板块或市场整体）已持续走强，用户想判断这个趋势是否已确立、追入的风险有多大。

### 语言信号 (用户的话里出现这些就应激活)

- "现在是牛市还是熊市？"
- "这轮行情能持续多久？"
- "市场对这个利空为什么没反应？"
- "现在是戴维斯双击还是双杀？"
- "这个上涨是水牛吗？"
- "趋势已经形成了吗？值得追吗？"
- "是不是该逃顶了/该抄底了？"

### 与相邻 skill 的区分

- 与 `capacity-cycle-positioning` 的区别：Skill D 聚焦于中观行业层面的产能周期定位（判断一个行业处于产能四阶段的哪个位置），本 skill 聚焦于宏观市场层面的牛熊性质和切换信号。
- 与 `external-shock-transmission` 的区别：Skill E 聚焦于外部冲击如何通过三层管道传导至A股（完整的传导链分析），本 skill 的脱敏部分只关注市场对冲击反应的衰减过程——是 Skill E 冲击分析的一个特定子场景。
- 与 `historical-stage-benchmarking` 的区别：Skill B 是通过"像不像像"三阶段认知模型寻找历史对标阶段，本 skill 是用具体信号指标直接判断当前市场的状态，不依赖于找到历史类比期。

## E — 可执行步骤 (Execution)

当 skill 被激活后, agent 应按以下步骤执行。**总时间估算**：完整执行约需30-60分钟（假设已有数据源）。步骤1-4是核心流程，步骤5-6为可选增强检查。

1. **数据收集与分子端检验**
   - 收集：指数涨跌幅、PE/PB分位数、两融余额、北向资金流向、全市场ROE趋势、盈利增速方向（一阶导和二阶导）。
   - 完成标准: 给出"盈利趋势向上/走平/向下"的判断，标注置信度。若盈利数据严重滞后或受一次性因素扭曲，标记"分子端信号不可靠"。
   - 判停条件: 若盈利趋势无法判断（数据矛盾），跳至步骤4降低所有结论置信度。

2. **分母端检验与牛市性质判定**
   - 流动性环境：货币政策方向、社融增速、增量资金来源（两融/北向/新发基金）。风险偏好：ERP位置、波动率、涨停跌停比。
   - 将分子端与分母端交叉对照：盈利向上+流动性配合=业绩牛；盈利走平/向下+流动性推涨=水牛。
   - 完成标准: 给出"水牛/业绩牛/混合型/无法判断"结论 + 3-5条证据。解释当前由哪个因子主导。
   - 判停条件: 若流动性宽松但风险偏好低迷，标记"流动性陷阱"风险。

3. **戴维斯双击/双杀扫描**
   - 将步骤1的盈利趋势与步骤2中观察到的估值分位交叉：盈利向上+估值中低位=双击环境（有利）；盈利向下+估值中高位=双杀环境（危险）；其他=中性。
   - 若盈利趋势与估值方向背离（盈利好但估值压缩/盈利差但估值扩张），标记"背离信号"——可能存在尚未被定价的重要变量。
   - 完成标准: 给出"双击/双杀/中性"判断，计算若盈利增速变化±10%在目前估值下股价的理论影响区间。

4. **脱敏检测**
   - 梳理近6-12个月反复冲击事件，对比每次市场反应幅度（跌幅/波动率/恢复天数）。检查三条件：冲击可预期、对冲可信、内因强于外因。
   - 完成标准: 每个冲击因素给出脱敏评级（已脱敏/部分脱敏/未脱敏）+ 证据。
   - 判停条件: 若冲击从关税升级变为技术封锁（质性变化），脱敏判断需重置。

5. **周期折价检查** [来自 supplement.md 圣农发展教训]
   - 若行业存在"业绩持续增长但股价长期滞后"的模式，检查是否存在"周期折价"——市场因行业强周期属性给予永久性估值折价，使基本面改善信号成为假阳性。
   - 完成标准: 若检测到周期折价，明确标注"该行业/公司的盈利改善可能不会完全转化为股价涨幅"。
   - 判停条件: 若行业估值中枢出现结构性上移（如外资定价权提升、行业属性切换），周期折价可能正在消退。

6. **综合结论与跟踪清单**
   - 汇总步骤1-5，给出当前市场状态标签（业绩牛初期/末期/水牛期/双杀期/底部脱敏期）、主要风险来源、需跟踪的关键信号。
   - 完成标准: 输出≤5条的"信号检查清单"，每条含"如果X信号出现，则Y判断需修正"的条件语句。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **个股层面的判断**: 本 skill 的全部信号和框架是为市场整体或大类风格（大盘vs小盘、成长vs价值）设计的，不适用于单只股票的买卖判断。单只股票的牛熊受公司自身基本面、行业格局、管理层行为等因素主导，本 skill 的分辨框架无法有效迁移。
- **非A股市场**: 水牛vs业绩牛的分辨逻辑建立在A股特定的投资者结构（散户占比高、政策敏感性强、杠杆工具特殊）和历史经验上，美股、港股等其他市场的涨跌驱动机制不同，直接套用可能误导。
- **高频/短期交易**: 本 skill 的信号体系着眼于中期（季度到年度）的市场阶段判断，不适用于日频或周频的择时交易。脱敏信号、盈利趋势确认都需要数周到数月的时间来验证。
- **纯债券/商品市场**: 戴维斯双击/双杀框架基于"盈利+估值"的权益定价逻辑，在纯债券或商品市场不适用。脱敏机制虽有一定通用性，但传导路径和验证条件完全不同。

### 作者在书中警告的失败模式

- **"水牛"时间边界不可靠**: 作者回溯2005-2019年数据得出"基本面下行时流动性驱动的上涨不超过一个季度"的规律，但2015年是该规律唯一的反例——在杠杆叠加下，水牛从2014年7月持续到2015年6月（近一年）。这意味着"水牛何时结束"的判断缺乏可靠的时间框架，风险偏好持续的时间是"策略体系几乎无法解决的难题"（作者自认）。
- **"有预期"不等于"price in"**: 作者在复盘2018年时明确指出"有预期和price in是两回事"——即使市场知道某个利空将至（如贸易摩擦升级），也不代表价格已经充分反映。脱敏判断不能仅凭"市场已经知道这个利空"就下结论，必须有实际的"市场反应逐次减弱"的证据链。
- **"这次不一样"是最昂贵的四个字**: 当基本面的确发生结构性变化时，"这次不一样"的叙事最具有迷惑性。作者指出2016年"容易看错的关键在于基本面出现非线性的变化"——这种时候最容易被误认为是"新范式"而忽视历史规律。

### 作者的盲点 / 时代局限

- **成书于2020年，缺少后疫情时代的极端场景**: 书中的结论截至2020年，未覆盖2022-2023年美联储暴力加息周期、2024年A股924行情等新事件。这些新场景可能提供了"水牛"的新形态（如政策预期驱动的急速拉升），也可能提供了"脱敏"失败的新案例。
- **对极端风险偏好的成因讨论不足**: 书中将2015年创业板泡沫等"脱离基本面的极端行情"归为"风险偏好极端化"，但对其形成机制（社交媒体放大效应、算法交易的拥挤效应、量化策略的同质化等）的探讨深度不够。在水牛识别中，仅靠传统信号可能低估了新传播环境下的风险偏好膨胀速度。
- **A股投资者结构正在快速变化**: 书中隐含的专业机构视角，在量化基金占比快速提升、ETF被动投资崛起、社交媒体影响散户行为的新环境下，某些历史信号（如新增散户账户数）的指示意义可能在弱化，新的信号（如ETF资金流向、雪球产品敲入规模）需要被纳入体系。

### 容易混淆的邻近方法论

- **与纯粹的技术分析混淆**: 本 skill 的方法论不是看图说话——它要求从基本面（盈利趋势）、资金面（流动性和投资者结构）、行为面（风险偏好和脱敏）三个维度交叉验证。仅看K线形态或技术指标（如"金叉死叉"、RSI超买超卖）不属于本框架。
- **与宏观经济预测混淆**: 本 skill 不预测GDP、CPI、PMI等宏观变量，而是将这些变量作为信号体系的输入，聚焦于"市场定价中已经反映了多少"和"市场对这些变量的反应模式是否在变化"。宏观经济预测是上游输入而非本 skill 的输出。
- **与绝对估值模型混淆**: DCF/DDM模型精确计算内在价值不是本 skill 的目的。戴维斯双击/双杀框架使用的是方向和相对位置判断（"盈利趋势在改善"+"估值在中低位"），而非精确的目标价计算。

- **composes-with** [policy-driver-assessment](../policy-driver-assessment/SKILL.md) -- 两者互补：本 skill 从价格/估值/资金行为的市场信号出发判断行情性质（水牛vs业绩牛），政策驱动力评估从政策、基本面、资金面三个源头驱动力出发预判行情级别和持续性。市场信号+驱动力分析双角度交叉验证，提高判断可靠性。
- **contrasts-with** [historical-stage-benchmarking](../historical-stage-benchmarking/SKILL.md) -- 两套可选判断框架：本 skill 用具体信号指标直接判断当前市场状态（不依赖历史类比），历史对标系统通过寻找相似历史阶段来做判断。当前市场与历史有高质量对标时倾向后者；面临全新范式（如AI革命）时优先使用前者。
