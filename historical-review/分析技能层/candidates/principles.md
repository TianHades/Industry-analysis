# 候选原则 (Principle Candidates)

## p01: 三因子定价框架——基本面趋势、流动性、风险偏好

- **类型**: rule
- **来源章节**: "中国资本市场激荡30年" + 贯穿全书
- **原文引用**:
  > 基本面趋势决定方向，流动性决定弹性，风险偏好决定波动。牛市中三因子共振向上，熊市中三因子共振向下，震荡市中因子方向分歧。
- **摘要**: 作者反复强调的A股定价核心框架。基本面趋势（企业盈利方向）决定指数中长期走向，流动性（货币/信用环境）决定涨跌幅度，风险偏好（市场情绪）决定短期波动大小。识别当前主导因子是第一要务。
- **适用场景**: 任何时点对A股整体走势进行研判时，应先拆解三因子各自方向，判断是共振还是分歧。
- **标签**: [A股定价, 三因子, 大势研判, 核心框架]

## p02: "这次不一样"是最昂贵的四个字

- **类型**: maxim
- **来源章节**: 前言 + 全书反复出现
- **原文引用**:
  > 几乎每一年的市场参与者都觉得"这次不一样"，但回看20年，因子和规律高度重复。不一样的是具体事件，一样的是人性反应和机制传导。
- **摘要**: 作者从20年复盘得出的meta-lesson。每一年都有独特事件（SARS、金融危机、钱荒、贸易摩擦、新冠疫情），但市场对冲击的反应模式高度可归纳。当投资者用"这次不一样"说服自己忽略历史规律时，往往是重大误判的开始。
- **适用场景**: 当面对新的宏观冲击或市场极端行情，本能反应是"这一次和历史上任何一次都不同"时，应回归三因子框架检验。
- **标签**: [行为金融, 逆向思维, 历史规律, 人性]

## p03: 不要有行业偏见——风格切换是常态

- **类型**: maxim
- **来源章节**: "第7节 从快牛到慢牛：2015—2017年A股简要复盘"
- **原文引用**:
  > 不要有行业偏见——这也许是2016年最重要的一课。对于经历2013年、2015年成长股行情的投资者来说，突然要切换成周期股，其实内心深处很难接受。
- **摘要**: 2016年供给侧改革驱动周期股行情，让习惯了成长股投资的基金经理措手不及。作者用这个案例告诫：A股风格轮动是常态，任何行业偏好固化都会导致踏空或深套。无偏见的行业比较是专业投资者的基本素养。
- **适用场景**: 当某个风格/行业持续跑赢超过2-3年、市场形成"信仰"时，应警惕风格切换风险，主动研究被市场冷落的方向。
- **标签**: [风格切换, 行业偏见, 周期股, 成长股, 行为金融]

## p04: "万物皆周期"——所有行业共享宏观共振

- **类型**: rule
- **来源章节**: "后记：'万物皆周期'VS.'穿越周期'"
- **原文引用**:
  > 平时工作繁忙甚少见面的分析师们总是不约而同地把2008年、2016年等年份作为行业重要阶段的分水岭，钢铁煤炭行业如此，先进制造行业如电气设备亦如此，就连一部分所谓周期性更弱的行业（食品饮料、医药生物）也"碰巧"如此。这背后是显然宏观驱动力之间的共振，不得不让人感叹"万物皆周期"。
- **摘要**: 即便是被归类为"弱周期"的消费行业（食品饮料、医药），其行业阶段拐点也与宏观大年（2008、2016）高度重合。这说明不存在完全脱离宏观周期的行业，只有周期敏感度不同。在做行业研究时，不能因为"弱周期"标签而忽略宏观背景。
- **适用场景**: 分析任何行业的阶段定位时，必须先审视宏观背景（经济周期位置、政策方向、流动性环境），而非仅看行业自身逻辑。
- **标签**: [宏观共振, 行业周期, 阶段分水岭, 跨行业共性]

## p05: 穿越周期的三个必要条件

- **类型**: rule
- **来源章节**: "后记：'万物皆周期'VS.'穿越周期'"
- **原文引用**:
  > 我们所说的"穿越周期"，可能最乐观的情况也就是在合适的估值下（很难事前判断，往往发生在事后被证明是底部的位置）买到了优质资产，且我们对这些资产的主观判断在随后几年有幸被证实。只要是做单纯的、不择时的股票多头投资，始终无法逃开回撤控制等问题。
- **摘要**: 作者冷静地指出"穿越周期"的真实条件：①在事后才被证明是底部的估值位置买入；②买入的是真正优质的资产；③主观判断有幸被随后几年验证。三者缺一不可。同时坦承：不择时的纯多头组合永远无法逃避回撤。
- **适用场景**: 当宣称某公司/行业可以"穿越周期"时，应逐一检验这三个条件是否满足，并对自己的判断保持谦逊。
- **标签**: [穿越周期, 估值, 优质资产, 回撤控制, 投资纪律]

## p06: 坚守可买资产——高ROE/高增长组合长期制胜

- **类型**: rule
- **来源章节**: "LIFE ALWAYS FINDS ITS WAY OUT——中国资本市场激荡30年"
- **原文引用**:
  > 如果我们一直坚持买入高ROE和高增长的个股，将获得可观的净值增长。2005年5月至2019年11月，高ROE组合、高增长组合、公募基金top200组合累计净值增长分别达850%、468%和690%。
- **摘要**: 用长达14年的数据证明：持续持有高ROE或高增长的优质公司（"可买资产"）是最确定的中长期收益来源。即使指数不再创新高，可买资产组合仍可创净值新高。这是全书最硬核的长期投资规则。
- **适用场景**: 构建中长期投资组合时，应以ROE和可持续增长率为核心筛选指标，而非追逐短期主题或风格。
- **标签**: [可买资产, ROE, 长期投资, 选股, 复利]

## p07: 外因最终通过内因起作用——从分子到分母的传导

- **类型**: rule
- **来源章节**: "千磨万砺还坚劲——近20年海外因素对A股市场影响的历史复盘·总结"
- **原文引用**:
  > 海外因素的变化最终通过国内资本市场的基本面和流动性环境等方面影响国内资产价格的表现。可以看到近几年随着中美之间基本面（分子层面）相关度的下降，分母层面流动性、风险偏好层面影响正在上升。
- **摘要**: 海外因素通过三层管道影响A股：全球商业周期（分子端盈利）、美元周期/美联储政策（分母端流动性）、政治周期（风险偏好）。当中美经济周期同步时，分子端传导为主；当经济周期分化时，分母端（流动性/情绪）传导上升。因此分析海外冲击时，先判断当前中美商业周期是同步还是分化。
- **适用场景**: 分析美股波动、美联储政策、美元走势对A股的影响时，先定位中美经济周期关系，再确定主导传导管道。
- **标签**: [海外因素, 传导机制, 分子分母, 美元周期, 中美关系]

## p08: 需求决定方向，供给决定弹性——产能周期核心规律

- **类型**: rule
- **来源章节**: 贯穿中篇多个行业复盘（光伏、工程机械、有色、煤炭、造纸）
- **原文引用**:
  > 需求决定方向，供给决定弹性。
- **摘要**: 书中最精炼的供需法则。行业景气方向由需求变化决定（增长/萎缩→行业向上/向下），但盈利弹性由供给端状态决定（产能紧张时需求增长带来暴利，产能过剩时需求增长仅能消化库存）。全行业复盘反复验证这一规则。
- **适用场景**: 判断任何周期性行业的盈利拐点和弹性时，先看需求方向，再看供给格局（产能利用率、在建产能、库存水位）。
- **标签**: [供需法则, 产能周期, 盈利弹性, 周期行业]

## p09: 品牌是白酒公司最重要的资产——历史积淀不可复制，品牌掉队不可逆

- **类型**: rule
- **来源章节**: "第2节 食品饮料行业全景复盘——白酒复盘"
- **原文引用**:
  > 品牌是白酒公司最重要的资产，白酒品牌是被时代所选择的，品牌出身是白酒行业的天然壁垒，历史积淀难以复制。一个品牌的培养往往需要数十年，历史上每一轮行业洗牌，都是品牌掉队的过程，并且不可逆袭。名酒品牌会越来越少，品牌的稀缺性会越来越明显。
- **摘要**: 白酒行业的核心竞争壁垒不是产能、不是渠道、不是价格，而是品牌。品牌需要数十年培养，一旦在行业洗牌中掉队就无法挽回。这决定了白酒投资的根本逻辑：买品牌力最强、最稀缺的名酒龙头，而非追弹性或估值便宜的二三线品牌。
- **适用场景**: 分析白酒（乃至高端消费品）的投资价值时，品牌强度和稀缺性应作为第一筛选标准，而非短期增速或估值。
- **标签**: [品牌壁垒, 白酒, 消费行业, 不可逆, 稀缺性]

## p10: 消费升级与份额向头部集中是消费行业核心驱动力

- **类型**: rule
- **来源章节**: "第2节 食品饮料行业全景复盘——白酒复盘·总结"
- **原文引用**:
  > 中长期看，消费升级与份额向头部集中将驱动名酒品牌的量价齐升，进而实现收入与业绩稳定的增长。
- **摘要**: 2015年后白酒行业产销量已放缓甚至下降，但名酒品牌通过消费升级（提价）+份额集中（扩量）实现了超越行业的增长。这一逻辑不仅适用于白酒，也适用于调味品、乳制品、家电等众多消费品类——从总量驱动转向结构驱动。
- **适用场景**: 当消费行业整体增速放缓时，不应简单结论"行业见顶"，而应分析消费升级和集中度提升能否为龙头创造独立增长空间。
- **标签**: [消费升级, 集中度, 龙头, 结构性增长, 量价关系]

## p11: 大行业出大市值公司

- **类型**: rule
- **来源章节**: "第9节 农林牧渔行业全景复盘——在复盘中提炼中国农业投资选择"
- **原文引用**:
  > 大行业体量才能孕育大市值公司。已有的农业大市值公司，如金龙鱼（4890亿元）、牧原股份（2674亿元）、温氏股份（1172亿元）、海大集团（988亿元）等，主要分布在粮油加工、生猪养殖、饲料加工等农业大子行业。而生物股份（241亿元）、登海种业（186亿元）市值则相对较小，或掣肘于行业体量。
- **摘要**: 公司市值的天花板首先由行业体量决定。寻找大市值牛股的第一步是判断行业市场空间是否足够大。在小行业里即便做到绝对龙头，市值天花板也较低。这是选赛道的基础法则。
- **适用场景**: 评估一家公司长期市值空间时，先测算其所在行业的TAM（总可寻址市场规模），大行业是大市值公司的必要条件。
- **标签**: [市值天花板, 行业体量, 赛道选择, 大行业]

## p12: 基本面趋势一旦形成即很难证伪

- **类型**: rule
- **来源章节**: "后记：唯有时代，盛开着永不凋零"
- **原文引用**:
  > 2017年最后验证了，基本面趋势一旦形成即很难证伪，龙头趋势未完。
- **摘要**: 这是作者复盘2017年龙头股行情得出的关键判断。当基本面向好趋势确立后，市场会沿着趋势方向持续定价，中途的怀疑和回调往往被证明是买入机会。这不是说趋势不会结束，而是趋势的持续性往往超出大多数人的预期。
- **适用场景**: 当确认一个基本面趋势（如行业景气上行、龙头份额持续提升）已经形成时，不要过早逆势，趋势的惯性往往大于预期。
- **标签**: [趋势投资, 基本面, 动量, 龙头, 持续性]

## p13: 没有核心资产的时代，只有时代的核心资产

- **类型**: maxim
- **来源章节**: "后记：唯有时代，盛开着永不凋零"
- **原文引用**:
  > 没有核心资产的时代，只有时代的核心资产。核心资产的确立是个结果……错把趋势当永恒，必然会错失下个时代的机遇。
- **摘要**: 全书最具哲学意味的箴言。"核心资产"不是固定不变的一批股票，而是每个时代经济主线的映射。2003年的核心资产是"五朵金花"（钢铁、石化等），2017年变成了消费龙头。用过去的"核心资产"名单指导未来投资是刻舟求剑。
- **适用场景**: 当市场形成高度共识的"核心资产"名单时，应警惕名单固化风险，主动思考下一个时代的经济主线可能在哪里。
- **标签**: [核心资产, 时代主线, 结构性变化, 反共识]

## p14: 流动性边际宽松是周期性行业超额收益的充分条件

- **类型**: rule
- **来源章节**: "第13节 房地产行业全景深度复盘·结语" + "第11节 建筑装饰行业全景复盘·结语"
- **原文引用**:
  > 流动性边际宽松是地产板块取得超额收益的充分条件。流动性的宽松与否在需求端决定了地产销售的景气度，而且在供给端，流动性也决定了地产企业的融资的量和价，所以在宽松的流动性环境下，地产板块更容易产生超额收益。
- **摘要**: 房地产和建筑等周期性行业获得超额收益的共同规律：必要条件是对核心驱动力形成乐观预期且股价尚未充分反映，充分条件是流动性边际宽松。仅靠政策预期（必要条件）不够，必须有流动性配合（充分条件）才能形成持续性行情。
- **适用场景**: 判断地产、建筑等政策敏感型周期性行业的投资时机时，先检查政策预期（必要条件），再检查流动性环境（充分条件），两者兼备时才可重仓。
- **标签**: [流动性, 房地产, 建筑, 必要条件与充分条件, 超额收益]

## p15: 银行行情需要基本面、政策面、资金面三重共振

- **类型**: checklist
- **来源章节**: "第12节 银行业深度复盘"
- **原文引用**:
  > 任何一轮行情，均离不开基本面、政策面及资金面的共振，且宏观环境是银行基本面的风向标。
- **摘要**: 银行股作为强周期+高杠杆行业，单独一个因素好转不足以驱动持续性行情。复盘显示三段主要银行行情（2012年底、2014年底、2017年）均由三面共振推动：宏观基本面企稳/改善 + 政策面边际宽松/风险化解 + 资金面增量入市/风格切换。缺任何一面，行情力度和持续性都会打折扣。
- **适用场景**: 判断银行股是否进入可投资区间时，逐一检查：①宏观基本面是否企稳？②政策面（货币政策、监管）是否边际宽松？③资金面是否有增量或风格切换迹象？
- **标签**: [银行股, 三面共振, 基本面, 政策面, 资金面, 发令枪]

## p16: 需求趋势性改善是铜价上涨最重要内在驱动力

- **类型**: rule
- **来源章节**: "第5节 有色金属行业三大子行业深度复盘——铜行业"
- **原文引用**:
  > 过去30年中没有出现铜需求疲弱但价格上涨的阶段。金融危机发生后，即使货币政策出现宽松，铜价仍然下跌；随着积极的财政政策和宽松的货币政策传导到实体经济，需求出现环比改善迹象，铜作为经济晴雨表开启上涨行情。铜价上涨幅度和需求增长与可持续性密切相关。
- **摘要**: 铜作为"经济晴雨表"，其价格规律极其清晰：没有真实需求支撑的铜价上涨从未在历史上出现过。单纯的货币宽松若未传导至实体经济需求，无法推动铜价上涨。铜价涨幅与需求增长的强度/可持续性正相关。这一规律可以推及多数资源品。
- **适用场景**: 分析铜及其他工业金属的投资机会时，应将需求趋势（而非货币宽松或供给收缩）作为第一验证指标。没有需求支撑的价格上涨应视为不可持续的"伪行情"。
- **标签**: [铜, 工业金属, 需求驱动, 经济晴雨表, 伪行情识别]

## p17: 供给往往"矫枉过正"导致价格周期波动——小金属投资铁律

- **类型**: rule
- **来源章节**: "第5节 有色金属行业三大子行业深度复盘——钴锂行业"
- **原文引用**:
