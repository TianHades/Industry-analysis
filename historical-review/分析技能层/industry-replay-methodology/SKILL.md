# 行业复盘执行方法论

## R — 原文 (Reading)

> 一般来说，复盘会经历"像→不像→像"的过程。第一个"像"，往往是某几个资产价格组合或者市场表现跟历史很像。第二个"不像"，是发现了某些重要的因素和历史上存在偏差。最终回到第三个"像"是最难的，为什么我们总说历史会重演，并不是说两个时期的所有重要条件完全相同，而是最终市场做出了类似的反应——涨或跌、类似的风格和行业表现。为什么做出了类似反应，大的宏观环境肯定是基础，而信息的扩散和预期的形成是更加艺术的部分。
>
> — 上海申银万国证券研究所有限公司，上篇后记"给我一部时光机"

---

## I — 方法论骨架 (Interpretation)

申万宏源策略团队的行业复盘不是简单的"翻历史书找相似"，而是一套可被标准化执行的认知迭代流程。这套方法论的核心思想是"信号优先、驱动力验证"——先看市场发出的信号（价格变动、估值变化、资金流向），再回到基本面中寻找驱动力对信号进行验证或证伪，而不是用先验逻辑强行解释一切。

完整的复盘流程包含六个环节：（1）整理事件日历——将行业过去N年的重大事件按时间轴排列，建立"当时的信息集"，避免后见之明；（2）识别市场信号——梳理每次大行情/大回调对应的价格变动、估值变化、资金行为，形成"信号日志"；（3）匹配基本面驱动力——对每一段重大行情寻找对应的基本面证据（政策变化、盈利拐点、技术突破、供需格局改变），判断驱动力是否可持续；（4）做跨期类比——执行"像不像像"三阶段认知：先找表面相似的历史阶段（第一个"像"），再识别当前与历史的本质差异（"不像"），最后在驱动力层面寻找共性规律（第三个"像"）；（5）建立关键假设表——将核心判断显性化为3-5个可被事后验证的关键假设，设定验证时间窗口；（6）定期验证修正——不是"看对或看错"的二元判断，而是"假设为什么需要修正"的认知迭代。

这套方法论的独特性在于：它是从近10位分析师、7000天事件日历、每周讨论的机构级实践中提炼出来的。将其降维为个人可执行SOP的关键，是将"信号-驱动力验证"的闭环做到轻量但完整——不追求覆盖所有信息，但确保逻辑链条不断裂。

## A1 — 书中的应用 (Past Application)

### 案例: 申万宏源策略团队的7000天系统性复盘

- **问题**: 如何确保对中国资本市场20年历史的复盘不是"后见之明"或"叙事陷阱"，而是能够为当下投资决策提供可复用规律？
- **方法论的使用**: 团队逐日整理了A股2003-2020年约7000个交易日的大事件日历，用统一的"基本面-流动性-风险偏好"三因子框架贯穿所有复盘，以"信号-驱动力验证机制"为核心方法，每周开会讨论当前信号背后的驱动力是否可持续。在复盘过程中，团队经历了"像不像像"的完整认知过程——起初发现不同年份的资产价格走势相似（第一个"像"），随后发现关键变量的本质差异（"不像"），最终在驱动力层面回归到一致性理解（第三个"像"）。
- **结论**: 中国资本市场20年的历史存在可被系统分析的规律——基本面趋势决定方向、流动性决定弹性、风险偏好决定波动。历史不会简单重演，但能提供"可能性的边界"。"这次不一样"是市场参与者在每一轮周期都会犯的错误，而去回答"这次到底哪里一样、哪里不一样"才是复盘的核心价值。
- **结果**: 这套方法论支撑了全书对A股宏观8个阶段、22个行业共计约157万字的系统性复盘，成为中国卖方研究历史上规模最大的复盘工程之一。后记中坦承复盘存在"芝诺的圆"的局限——越深究越了解得不够，但正是这种"不可知论"驱动了持续的方法论迭代。

### 案例 2: 个人投资者复盘新能源车行业（方法应用示例）

- **问题**: 一个个人投资者想在2025年初建立对新能源车行业的系统性认知——行业经历了2019-2022年的爆发式增长，2023-2024年增速放缓、价格战加剧、部分新势力陷入困境。如何用这套方法论在2个周末内完成深度复盘？
- **方法论的使用**: 按五步SOP执行——(1)事件日历：梳理2020-2024年每月关键事件（补贴退坡节点、碳酸锂价格暴涨暴跌、特斯拉降价、小米入局、欧盟反补贴调查等），标注每次事件后行业ETF的涨跌幅；(2)信号日志：识别4段重大行情（2020-2021渗透率突破5%后的戴维斯双击、2022Q2供应链冲击、2023年价格战+估值压缩、2024Q4政策刺激反弹），记录每段行情的PE起点和资金行为；(3)驱动力匹配：发现2020-2021行情由"渗透率加速突破+政策补贴+盈利首次转正"三重驱动（业绩牛早期），2023年下跌由"产能严重过剩+价格战侵蚀盈利+估值从高位压缩"驱动（戴维斯双杀）；(4)跨期类比：第一个"像"——表面像2018年的光伏（补贴退坡后行业洗牌）；第二个"不像"——新能源车已实现用户端经济性（充电成本低于加油），不像2018年光伏仍需补贴；第三个"像"——在驱动力层面，更接近2009-2012年的工程机械（政策刺激透支需求→产能过剩→出清→龙头集中）；(5)关键假设表：列出5个假设及其验证时间窗口（如"CR5将在12个月内从55%升至65%"）。
- **结论**: 这套方法论可以在个人时间预算内（约20小时）完成对一个行业从"零基础"到"有结构化判断"的跨越。关键在于不求完美——第一个版本的假设表可以是粗糙的，核心价值在于建立了"后续应该盯什么指标"的跟踪框架。
- **结果**: 复盘完成后，投资者能够清晰回答"新能源车行业当前处于产能出清中段"的定位判断，并建立了"跟踪CR5月度变化+碳酸锂价格+月度渗透率"的核心指标体系，后续每周仅需30分钟即可完成跟踪更新。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill?

1. 用户面对一个完全陌生的行业（如合成生物学、商业航天），需要在一段时间内建立系统性的认知框架——"怎么系统研究一个新行业？"
2. 用户想做自己的行业复盘但缺乏结构化方法——"我想自己做行业复盘但不知道从哪开始。"
3. 用户对某个行业有一定了解但不确定自己的理解是否足够深入——"如何判断我对一个行业的理解够不够深入？"
4. 用户看到了书中对某个行业的精彩复盘，想知道背后的方法论——"申万宏源是怎么做这些复盘的？我能用同样的方法自己分析吗？"

### 语言信号（用户的话里出现这些就应激活）

- "怎么系统研究一个新行业"
- "我想自己做行业复盘但不知道从哪开始"
- "如何判断我对一个行业的理解够不够深入"
- "怎么建立行业分析框架"
- "我想学习如何复盘"
- "申万宏源是怎么做这些行业复盘的"

### 与相邻 skill 的区分

- 与 `historical-stage-benchmarking` 的区别：历史对标系统是复盘的"产出"（用"像不像像"做具体的历史类比），本skill是复盘的"方法"（如何执行整个复盘流程）。前者回答"现在像哪个历史阶段"，后者回答"怎么做完整的行业复盘"。
- 与 `industry-stage-locator` 的区别：产业阶段定位是复盘的"目标"之一（确定行业处于什么阶段），本skill是复盘的"全过程"（从零开始理解和跟踪一个行业）。
- 与 `bull-bear-signal-system` 的区别：牛熊信号体系是复盘产出的"信号词典"（有哪些可识别的切换信号），本skill教你如何自己去发现和验证这些信号。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行。以下SOP针对个人投资者的时间预算进行了优化。

**总时间预算参考（以一个新行业为例）**：深度复盘约需1-2个周末（16-32小时），快速建立认知框架约需1个周末（8-12小时），日常跟踪约需每周1-2小时。

1. **建立事件日历（时间预算：2-4小时）**
   - 梳理行业过去3-5年的重大事件，按时间轴排列。事件来源：行业政策文件、龙头公司财报发布时间节点、行业研报标题中的重大事件、百度/Google新闻搜索按年检索。
   - 关键动作：对每个事件标注当时市场的反应（涨/跌/平+幅度），形成"事件-反应"对照表。
   - 完成标准：事件日历覆盖过去3-5年每月至少1个关键事件，且每个重大行情节点都有对应的事件标记。
   - 判停条件：若行业信息严重不足（新兴行业缺乏公开数据），跳过此步直接告知用户局限性，使用步骤4的类比方法做替代。

2. **整理信号日志（时间预算：1-2小时）**
   - 获取行业ETF或主要公司股价走势图，标注每一段涨幅>30%或跌幅>20%的区间。
   - 对每一段重大行情记录：起始估值（PE分位数）、期间资金流向（北向资金/主力资金变化）、行情驱动的核心叙事（市场上当时在讲什么故事）。
   - 完成标准：每段重大行情都有估值起点+资金行为+核心叙事的记录。

3. **匹配驱动力并做第一轮验证（时间预算：2-3小时）**
   - 对每一段重大行情，寻找基本面驱动力证据：政策变化、盈利数据（营收增速、毛利率变化、ROE趋势）、技术突破、供需格局改变。
   - 执行"信号-驱动力"对照：行情方向与基本面驱动力方向是否一致？涨幅是否被盈利增速支撑？
   - 完成标准：判断每一段行情是"业绩驱动"（有盈利支撑）还是"水牛/情绪驱动"（缺乏盈利支撑），并将判断记录下来。
   - 判停条件：若大部分行情的驱动力无法与信号匹配，说明对该行业的理解还不够，应回到步骤1补充事件背景。

4. **执行"像不像像"跨期类比（时间预算：1-2小时）** ★ 此步可调用 `historical-stage-benchmarking` skill 辅助
   - 第一个"像"：从22个行业的历史复盘中找到最相似的可对标产业原型。判断标准：行业驱动力类型（技术驱动/投资驱动/资源周期/消费品牌/政策驱动）一致。
   - 第二个"不像"：列出当前行业与对标行业在至少3个关键变量上的本质差异（如政策环境、全球化程度、技术成熟度、竞争格局）。
   - 第三个"像"：在驱动力层面寻找共性规律——对标行业在类似阶段经历了什么？什么信号标志着阶段切换？什么陷阱最常见？
   - 完成标准：产出一份简短的"对标分析笔记"，包含对标行业名称+3个相似点+3个不同点+1条从对标中获得的假设。
   - 若对标分析较复杂（如多候选行业需筛选），建议显式调用 `historical-stage-benchmarking` skill 处理此步骤。

5. **建立并维护关键假设表（时间预算：初次1小时，后续每周30分钟）**
   - 将核心判断显性化为3-5个关键假设，格式：假设内容 + 验证指标 + 验证时间窗口 + 如果假设被证伪的应对方案。
   - 示例假设："假设X行业的渗透率将在12个月内突破15%的临界点。验证指标：月活用户/装机量数据。如果第6个月渗透率仍低于10%，则该假设需要修正。"
   - 定期（建议每季度或每次重大事件后）回顾假设表：哪些假设被验证了？哪些需要修正？修正的原因是什么（是数据问题还是底层逻辑错误）？
   - 完成标准：假设表持续维护中，至少每季度有一次正式的假设回顾记录。

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **纯粹追涨杀跌的短线交易**: 如果用户的目的是根据K线形态做日内或数日的短线交易，不需要行业复盘——短期价格由情绪和资金博弈主导，不是基本面驱动力。复盘方法论的回报周期以季度和年为单位。
- **信息严重不足的新兴行业**: 如果行业缺乏至少3年的价格和基本面数据（如2025年的太空旅游、可控核聚变），无法建立有意义的事件日历。此时复盘让位于"逻辑推演+技术可行性分析"，更适合使用 `industry-stage-locator` 做阶段定位。
- **用户期望复盘能精确预测未来**: 复盘提供的是"可能性的边界"而非"明天的涨跌方向"。如果用户的问题是"明天涨还是跌"，本方法论无法回答。复盘的价值在于提高中长期判断的胜率，而非短期择时。

### 作者在书中警告的失败模式

- **ce15（"芝诺的圆"——复盘方法论的内在局限）**: 作者坦承复盘越深究越发现不了解的东西越多。三个底层问题无解：如何确保还原的是历史真相？如何避免幸存者偏差？没有完全相同的市场环境，如何与当下比较？复盘的终点不是"确定性"而是"更结构化的不确定性管理"。
- **ce08（"这次不一样"是最昂贵的四个字）**: 当市场参与者开始广泛使用"这次不一样"为高估值辩护时，复盘的历史规律往往即将被验证。但同样危险的是，当基本面出现真正的非线性变化（如2016年），固守旧框架同样会误判。
- **p25（投资体系的持续完善重于单次判断的正误）**: 复盘不是为了让每一次判断都正确，而是为了持续完善投资体系的底层逻辑。即使正确执行了复盘流程，单次投资判断仍可能出错，但如果体系在持续改善，长期回报是可期的。

### 作者的盲点 / 时代局限

- **卖方机构的乐观偏差**: 申万宏源作为卖方研究所，有维护市场信心的隐性动机。"世界终将属于乐观者"的立场可能导致对长期系统性风险（如日本式资产负债表衰退）的复盘深度不足。
- **机构方法到个人方法的降维损耗**: 书本默认读者有团队支撑（近10位分析师、每周讨论会），但个人投资者缺乏这种资源。本skill试图弥补这一差距，但必须坦承：个人投资者执行的事件日历精度和驱动力验证深度，无法与机构相比。
- **信息扩散环境的变化**: 成书于2020年，彼时的信息传播生态（以研报和财经媒体为主）与2025年的短视频、AI分析工具、社交投资平台环境显著不同。信息的扩散速度和预期的形成方式已发生变化，这会影响"第三个像"中信息扩散机制的可比性。

### 容易混淆的邻近方法论

- **Graham的价值投资分析**: 格雷厄姆的方法是自下而上的公司分析，复盘的着眼点是行业整体而非个股。两者互补但不相同。
- **彼得·林奇的"翻石头"调研**: 林奇强调实地调研和草根观察，复盘强调系统性梳理历史规律。前者偏向定性直觉，后者偏向结构化思维。
- **技术分析的"历史会重演"**: 技术分析假设价格形态重复出现，复盘假设驱动力机制重复出现。前者基于价格图表，后者基于基本面逻辑链。
