# 历史阶段对标系统

## R — 原文 (Reading)

> 一般来说，复盘会经历"像→不像→像"的过程。第一个"像"，往往是某几个资产价格组合或者市场表现跟历史很像。第二个"不像"，是发现了某些重要的因素和历史上存在偏差。最终回到第三个"像"是最难的，为什么我们总说历史会重演，并不是说两个时期的所有重要条件完全相同，而是最终市场做出了类似的反应——涨或跌、类似的风格和行业表现。为什么做出了类似反应，大的宏观环境肯定是基础，而信息的扩散和预期的形成是更加艺术的部分。
>
> — 上海申银万国证券研究所有限公司，上篇后记「给我一部时光机」

---

## I — 方法论骨架 (Interpretation)

历史阶段对标的本质不是"找相似"，而是一个**三段递进式的认知校准过程**，每一步都在修正上一步的结论。

**第一个"像"——表面相似。** 这是直觉层。我们看到当前的资产价格走势、行业表现、市场风格和历史上的某个阶段很相似，大脑自然地做出类比。这一步是必要的起点，价值在于提出假设而非得出结论。比如看到"政策密集出台+市场情绪高涨"就想到2009年，看到"新兴技术被热捧"就想到1999年互联网。但停留在此是危险的——第一个"像"的类比往往止于价格图形和叙事标签的层面，容易忽略结构性的差异。

**第二个"不像"——关键差异。** 这是批判层。必须系统地列出当前与对标历史阶段之间**在关键变量上的差异**。这些关键变量至少应包括：(a) 宏观环境——经济所处位置、通胀水平、利率方向；(b) 流动性/杠杆条件——钱从哪来、杠杆水平、金融体系的脆弱性；(c) 行业基本面——盈利驱动力结构、渗透率位置、竞争格局；(d) 制度框架——监管环境、交易机制、投资者结构；(e) 外部环境——全球商业周期位置、地缘政治格局、技术变革阶段。如果在3个以上的关键变量上存在实质性差异，第一个"像"就需要被修正甚至推翻。

**第三个"像"——驱动力层面的回归。** 这是跃迁层，也是最难的一步。当排除了表面相似中的干扰变量后，回到**驱动力层面**寻找共性：两段时期的市场是否在"基本面趋势、流动性方向、风险偏好位置"这三个维度上处于类似的组合？如果在驱动力层面相似（比如都是"盈利改善初期+流动性宽松+风险偏好低迷后刚修复"），那么即使具体事件不同，市场反应模式更可能趋同。反之，如果驱动力组合不同（比如价格走势相似但一段是盈利驱动一段是流动性驱动），则不应预期类似的结局。

**两个对称陷阱。** "这次不一样"是最昂贵的四个字——几乎每一轮牛熊的前夜都有人说"这次不一样"，但20年复盘证明底层的三因子机制高度重复。然而，对称的陷阱是"这次完全一样"——固守历史类比而忽略当下特有的结构性变化（如注册制改革、外资定价权上升、AI技术革命），同样会导致致命误判。两者的平衡点在于：**相信底层驱动力会重复，但并不假设表层事件和具体路径会重复。**

**永续预期的警示。** 市场对"永续增长"叙事的定价往往走在基本面之前。"没有核心资产的时代，只有时代的核心资产"——当市场开始广泛使用"永续""永远的赛道""核心资产"等词汇时，往往意味着定价已接近顶部。2003年的"核心资产"（公用事业、钢铁、石化）后来再也没回来；2017年的消费龙头确立是"时代的贝塔"，而非"永恒的公司阿尔法"。

## A1 — 书中的应用 (Past Application)

### 案例 1：2003年"核心资产"的确立与没落——"顶底领先永续预期"的残酷验证

- **问题**：2003-2004年，A股市场确立了第一批"核心资产"——以公用事业（电力）、钢铁、石化、汽车、银行为代表的"五朵金花"。当时市场叙事是：这些是"中国崛起不可或缺的战略资产"，具有永续增长前景。投资者应该买入并长期持有。
- **方法论的使用**：用"像→不像→像"审视这个叙事。(a) 第一个"像"——2003年的宏观环境是重工业化加速、城镇人口膨胀，和日本1960年代"国民收入倍增计划"期的重工业繁荣很像。价格走势上，周期股涨势如虹，和日本当年的钢铁、化工牛市高度相似。(b) 第二个"不像"——2003年的中国和1960年代的日本在制度基础、全球分工位置、资本市场成熟度上存在巨大差异。更重要的是，两国的人口结构轨迹在2000年代后完全不同。(c) 第三个"像"——在驱动力层面，2003年的周期股繁荣本质上是"盈利改善+估值修复"的业绩牛早期阶段，和历史上所有的周期股牛市一样，终将面临"产能扩张→供过于求→盈利下滑"的产能周期归宿。
- **结论**：当市场对一个行业的"永续增长"叙事形成高度共识时，**股价的顶部往往领先于"永续"预期的高峰**。公用事业在2004年后再无整体板块性机会，钢铁、石化过早验证了"逃不开的周期"。这一次验证了p24"顶底领先预期"的残酷性——"永续"两个字本身就是最危险的信号。
- **结果**：2003年辉煌的"核心资产"在随后十余年中经历了至少四次风格切换（周期→消费→互联网→龙头白马），每次切换都让上一轮的"永续信仰者"遭受沉重打击。2003年"五朵金花"中的大多数行业在此后长期跑输。

### 案例 2：2017年消费龙头成为"核心资产"——从"不像"到"像"的确认过程

- **问题**：2016-2017年，以茅台、五粮液、美的、格力、恒瑞为代表的消费龙头和医药龙头持续大涨，市场开始争论：这是不是新一轮"核心资产"的确立？还是另一个终将破灭的泡沫？
- **方法论的使用**：用三阶段框架分析。(a) 第一个"像"——2017年消费龙头的走势和2003年"五朵金花"很像：一批"最优质的资产"引领指数创新高，市场叙事从"估值修复"转向"永续增长"。"漂亮50"与"要命3000"的极致分化也让人想起2007年"大象起舞"时的结构性行情。(b) 第二个"不像"——与2003年周期股当道的核心资产不同，2017年的驱动力发生了根本性变化：供给侧改革出清了传统行业的过剩产能→行业集中度提升→龙头盈利质量系统性改善；MSCI纳入A股→外资持续流入→带来DCF思维的估值体系重塑；消费升级而非投资驱动成为增长新引擎；地产"房住不炒"定位意味着旧经济模式已不可逆。(c) 第三个"像"——在驱动力层面，2017年和2003年有一个深层共性：两轮"核心资产"行情都建立在**真实的基本面改善+增量资金入场**之上，而非纯流动性驱动（水牛）。这意味着它们都具有比纯水牛更强的持续性。但同时也意味着——当驱动力切换（如利率快速上行、宏观主线改变），核心资产的名单会再次洗牌。
- **结论**：2017年消费龙头成为核心资产有坚实的基本面支撑（集中度提升+消费升级+外资定价权），不是泡沫。但p13的警告必须牢记——"没有核心资产的时代，只有时代的核心资产"。当宏观驱动力再次切换时（如2021年初的利率上行导致核心资产估值冲击），即使是好公司也会经历剧烈回调。
- **结果**：消费龙头在2017-2020年获得显著超额收益，行业集中度持续提升。但2021年春节后长端利率上行引发核心资产估值压缩，验证了"龙头估值对贴现率愈发敏感"的规律。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. **宏观阶段对标**：用户面对当前的市场环境（如"政策密集出台+流动性宽松+经济企稳"），想知道历史上有没有类似的宏观组合。典型问题："现在像2009年还是2016年？"

2. **行业历史类比**：用户在分析一个新关注行业，想找到历史上类似产业原型作为参考。典型问题："AI基础设施赛道历史上最像哪个行业的哪个阶段？"

3. **当前叙事的"防骗"检查**：用户听到市场主流叙事（如"这次不一样""这是新的核心资产""永续赛道"），想验证这个叙事在历史上是否出现过以及结局如何。典型问题："现在市场说的'新范式'是不是和2007年、2015年高峰时说的一样？"

4. **跨周期的投资逻辑验证**：用户在构建投资逻辑，想检验逻辑基础是"时代的贝塔"还是"穿越周期的阿尔法"。典型问题："这家公司的竞争优势能不能扛过下一轮宏观切换？"

5. **"今年像哪年"类复盘训练**：用户在做个人的年度复盘或来年展望，想用历史对标的方法来系统性梳理"可能性空间"。典型问题："今年的市场环境和哪几年最像？那些年份后来发生了什么？"

### 语言信号（用户的话里出现这些就应激活）

- "现在像历史上的什么时候？"
- "这个行业有没有历史可以对照？"
- "这次和XX年像不像？"
- "这次是不是不一样？"
- "这个是不是新的核心资产？"
- "看看历史上类似的情况后来怎么样了？"
- "这件事在A股历史上有没有先例？"
- "给我一部时光机，回到过去看看"

### 与相邻 skill 的区分

- 与 `industry-stage-locator` 的区别：本 skill 是**向后看**——在历史中寻找可对标的时期/行业；`industry-stage-locator` 是**向前看**——用渗透率/增速/政策信号推断行业当前所处阶段。两者互补：先用 `industry-stage-locator` 定位阶段，再用本 skill 找历史参照和可能性边界。

- 与 `bull-bear-signal-system` 的区别：本 skill 关注的是"与哪个历史阶段对标"的宽框架，而 `bull-bear-signal-system` 聚焦于识别"当前是不是牛熊拐点"的具体信号体系。本 skill 的输出可以为后者提供历史参照的"可能性边界"。

- 与 `industry-replay-methodology` 的区别：本 skill 是成品——帮用户用已有的22个行业复盘做对标；`industry-replay-methodology` 是工具——教用户如何自己对新行业做复盘。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **收集对标所需的基础素材**
   - 询问或推断用户想要对标的目标（当前市场整体/某一行业/某一资产类别）
   - 收集当前的关键特征：基本面趋势（盈利方向、ROE水平）、流动性环境（利率方向、信用条件、增量资金来源）、风险偏好位置（估值分位数、情绪指标）、政策环境（力度、方向、节奏）
   - 收集驱动力的定性描述：当前行情的主要驱动力是什么（盈利驱动/流动性驱动/政策驱动/风险偏好驱动）？
   - **完成标准**：至少收集了"基本面、流动性、风险偏好、政策"四个维度的当前状态描述，且每个维度有至少一项可观测指标

2. **第一个"像"——提出至少2个历史对标候选并逐一比较**
   - 基于当前的特征组合，从书中22个行业的复盘历史中提出至少2个最相似的历史阶段候选
   - 对每个候选，列出相似点（价格走势、行业表现、市场风格、宏观背景、政策环境等）
   - 用表格做初步比较：当前 vs 候选A vs 候选B
   - **完成标准**：每个候选至少有5条相似点，且相似点不仅限于价格图形层面
   - **判停条件**：如果无法找到任何有相似驱动力的历史阶段（如AI革命级别的全新范式），诚实告知用户"最诚实的答案是：历史上没有很好的对标"，跳到 B 段边界说明并终止

3. **第二个"不像"——逐条列举关键差异**
   - 对每个候选，至少在以下五个维度逐一检查差异：
     - 宏观环境差异（经济周期位置、通胀水平、利率方向）
     - 流动性/杠杆条件差异（资金来源、杠杆水平、金融体系脆弱性）
     - 行业基本面差异（驱动力结构、渗透率位置、竞争格局）
     - 制度框架差异（监管环境、交易机制、投资者结构）
     - 外部环境差异（全球商业周期、地缘政治、技术变革阶段）
   - 标注每个差异是"可能改变结论的关键差异"还是"影响较小的次要差异"
   - **完成标准**：每个维度至少列出了1个差异点，关键差异被明确标注

4. **第三个"像"——在驱动力层面综合判断**
   - 综合前两步，回到三因子框架（基本面趋势+流动性+风险偏好），判断当前与历史对标在**驱动力层面**是否相似
   - 如果驱动力组合相似（如都是"盈利改善+流动性宽松+风险偏好修复"）：给出"历史规律可能适用"的判断，参考历史阶段编制"可能性边界"——最好情况、最差情况、最可能路径
   - 如果驱动力组合不同（如表面价格相似但一段是盈利驱动、一段是流动性驱动）：明确指出"虽然看起来像，但驱动力不同，不应简单套用历史走势"，给出差异化的展望
   - **完成标准**：输出明确结论（"驱动力相似/部分相似/不相似"），附上"可能性空间"的上下边界（不是单点预测），以及如果判断错了最可能是因为什么变量

5. **永续预期检查（防止叙事陷阱）**
   - 检查当前市场叙事中是否出现以下危险信号："永续""永远的赛道""这次不一样""核心资产=永远持有""新范式""新时代"
   - 如果出现，主动引用p13和p24进行警示："没有核心资产的时代，只有时代的核心资产"+"股价的顶底总是领先于永续预期的开始和结束"
   - 检查估值是否已处于历史极端位置（如PE在95%分位数以上），如果是则强化警示
   - **完成标准**：对叙事层面做出独立于基本面的风险评估，不被市场情绪裹挟

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **缺乏历史数据的新兴技术领域**：如2025年的某些AI应用子领域，历史上确实没有可对标的数据。如果"历史对标"变成了"强行找相似"，输出的类比可能比没有类比更危险。此时诚实地说"没有好的对标"比强行类比更有价值。

- **宏观制度环境发生根本性改变的切换期**：如当前A股正处于从审批制到全面注册制、从散户市到机构市的转换期，某些历史上基于"壳价值""小盘溢价"的规律可能永久性失效。在制度断层期使用历史对标时，必须首先声明"制度框架已发生根本改变"这个前提。

- **纯粹短期博弈或事件驱动型交易**：如"明天会涨吗""这个新闻对下周的影响"。历史对标针对的是中长期的阶段判断（至少季度以上尺度），不适用于日度和周度的短期交易决策。短期交易需要的是一套完全不同的工具（技术分析、事件冲击模型等）。

- **完全依赖量化回测而无定性判断的机械操作**：如果用户期望的是"输入几个指标→自动输出历史上最像的阶段→直接套用历史走势"的量化公式，这个 skill 不适合。第三个"像"需要的是定性的判断力和对"信息扩散与预期形成"的艺术性理解，机械回测达不到这个深度。

### 作者在书中警告的失败模式

- **"这次不一样"——市场最昂贵的四个字**（p02）：几乎每一轮牛熊的前夜都有人说"这次不一样"。2007年说"中国崛起改变一切"，2015年说"互联网+改变经济规律"，2017年说"核心资产永续成长"。事后回看，人性反应和机制传导高度重复。当"这次不一样"成为主流叙事时，恰恰是历史规律最可能重复的时候。

- **对称陷阱——"这次完全一样"同样是误判**：p02的警示另一面是：当市场执著于"这次和历史上某次完全一样"时，可能忽略了当下的独特变量。2011年券商集体用2009年的"交谊舞"框架预测政策转向和估值修复，结果全部猜错——因为宏观经济的底层驱动模式已经从"投资驱动"切换到"转型驱动"。同理，2025年量化的回测模型如果基于2003-2020年的历史数据，可能系统性低估了注册制、外资定价权、AI技术革命对市场结构的影响。

- **2003年"核心资产"的教训——错把趋势当永恒**（p13/ce09）：从2003年到2020年，"核心资产"的定义至少经历了四次大规模切换。每次"核心资产"的确立都伴随着坚实的时代逻辑，但每次切换都让前一论的"永续信仰者"遭受沉重打击。教训：在历史对标中，永远要识别"时代的贝塔"和"公司的阿尔法"，不要把前者错当后者。

### 作者的盲点 / 时代局限

- 全书复盘截至2020年，"像→不像→像"的历史对标库（22个行业+20年A股）以2003-2020年的数据为基础。2020年后的"双碳"全面落地、AI大模型革命、人口拐点、房地产深度调整、中美科技脱钩加速等事件，在历史对标库中没有对应的完整周期数据。这意味着用这套系统对标当前的新兴领域时，可能出现"找不到足够相似的历史参照"的情况——这不是方法论本身的问题，而是样本空间不足的客观限制。
- "芝诺的圆"——作者在ce15中坦承的复盘方法论内在局限：任何复盘都是选择性还原，存在幸存者偏差和后见之明。"像→不像→像"的过程高度依赖于执行者的经验和判断力，不同的人用同一套方法可能得出不同的结论。

### 容易混淆的邻近方法论

- **量化回测/因子匹配**：量化方法可以快速在历史数据库中找出统计上最相似的时期，但它只覆盖了第一个"像"（统计相似性）。"不像"（关键差异识别）和第三个"像"（驱动力定性判断）需要的是基本面理解和宏观框架洞察，量化做不到。两者可以互补但不能替代。
- **简单的"今年像哪年"**：市场上流传的"今年像2014年/像2016年/像2019年"往往是基于一两个指标或价格图形的粗粒度类比。本 skill 要求的多维度交叉验证和驱动力层面的回归，远比这类粗粒度类比严谨。
