# 产业阶段定位框架

## R — 原文 (Reading)

> 光伏产业发展可以分为三个阶段，经济性增强驱动行业从政策驱动期迈向过渡期，未来逐渐步入经济性驱动期。光伏发展初期成本高昂，经济性相对火电无竞争力，依赖政府补贴……经济性成为装机核心动力。
>
> — 上海申银万国证券研究所有限公司，中篇第1节「光伏行业深度复盘」

> 分析师们不约而同地把2008年、2016年作为行业重要阶段的分水岭，钢铁煤炭如此，先进制造亦如此，就连周期性更弱的消费行业也"碰巧"如此。不得不让人感叹"万物皆周期"。
>
> — 上海申银万国证券研究所有限公司，中篇后记「万物皆周期VS穿越周期」

## I — 方法论骨架 (Interpretation)

一个行业从诞生到成熟，可以用三阶段框架来定位它所处的位置。这个框架的核心不是绘制一条漂亮的S曲线，而是回答三个具体问题：**行业当前靠什么驱动？驱动力是否在切换？切换的临界信号是什么？**

**阶段一：政策驱动期（导入期）**。行业尚未实现经济性（成本高于现有替代方案），增长依赖外部推力——通常是补贴、牌照、税收优惠或强制性政策。核心观测指标不是营收增速或利润率，而是**渗透率的绝对水平和加速度**（如从3%突破5%）、政策力度和补贴规模、以及技术成本下降曲线的斜率。在这一阶段，行情主要由"预期"驱动——市场买的是"未来会变好"的故事，盈利支撑薄弱，股价对政策边际变化极度敏感。

**阶段二：过渡期（经济性增强但尚需隐性扶持）**。行业成本已大幅下降，部分场景实现经济性（如光伏的发电侧平价），但综合成本仍高于传统方案（如考虑调峰成本）。政策名义退坡但隐性扶持仍在（保障性收购、优先并网等）。核心判断标准：**渗透率是否突破了15-20%的临界区间**，以及**单位经济模型（UE）是否能打平**。此阶段行情从"纯预期驱动"向"预期+盈利双轮驱动"切换，行业内部分化加剧——具备技术和成本优势的龙头率先跑出。

**阶段三：经济性驱动期（成熟期）**。行业综合成本低于替代方案，内生需求成为装机/购买的核心动力。渗透率突破50%后增速自然放缓，行业从"增量竞争"进入"存量博弈"。核心观测指标从渗透率切换为**行业集中度（CR5/CR10）、龙头市占率变化、设备更新周期（如有）**。行情由盈利支撑主导，龙头获得估值溢价。

**额外的维度：设备更新周期。** 对于耐用品行业（工程机械、汽车、家电等），当行业从高速成长期进入成熟期，需求结构会发生本质变化——从"纯新增需求驱动"切换为"**存量更新需求 + 新增需求**"双轮驱动。识别这个切换的关键信号是：宏观投资增速与设备销量的相关性下降。设备更新周期（如8-10年）成为需求的基本盘，新增应用场景提供增量弹性。

**市值的双层驱动。** 行业市值（股价）在任何阶段都由"预期驱动层"和"盈利支撑层"共同决定，但权重随阶段变化。成长期预期权重更高，成熟期盈利权重更高。预期层看政策边际变化、竞争格局预期、利率环境；盈利层看销量、价格、成本三要素。识别当前市值主要由哪一层定价，是判断行情持续性的关键。

**⚠️ 适用范围说明。** 上述三阶段模型（政策驱动→过渡期→经济性驱动）主要适用于**技术迭代型**行业（光伏、通信、医药等），核心判断标准是渗透率+成本竞争力。对于**周期制造型**行业（煤炭、造纸、铜、油轮等），应使用 [框架文档第二章](../../行业生命周期全景框架_蒸馏笔记.md) 的六阶段模型（导入→成长→成熟→下行→出清→重生），核心判断标准是产能利用率+供需缺口+行业集中度。两种模型互补而非冲突——技术驱动行业看"渗透率S曲线"，周期驱动行业看"产能周期钟摆"。对于同时具备两种属性的行业（如光伏），两种模型应交叉验证。

## A1 — 书中的应用 (Past Application)

### 案例 1：光伏产业从政策驱动到平价上网的完整演化

- **问题**：光伏行业从2004年到2020年经历了多轮暴涨暴跌，投资者需要判断每一轮行情的性质是"政策催化的反弹"还是"经济性驱动的趋势"。
- **方法论的使用**：用三阶段框架定位每一轮行情。2004-2012年是典型的政策驱动期——西班牙、德国、中国的补贴政策直接决定了装机节奏和行情高度。2009年西班牙补贴退坡（装机骤减99%）和2012年欧美双反，两次重创都来自"政策驱动期需求断层"的经典机制——补贴退坡→产业链价格暴跌→高杠杆企业资金链断裂→龙头破产（无锡尚德、LDK）。2018年"531新政"是过渡期的标志性事件——补贴突然大幅缩减使国内装机骤降，但光伏成本已在海外多国实现发电侧平价，海外需求爆发接棒国内需求，行业仅4个月即触底反弹。这验证了过渡期的核心逻辑：**补贴退坡短期冲击需求，但价格暴跌加速触及平价临界点，一旦突破临界点，多元化全球需求会自动激发**。
- **结论**：识别一个行业是"政策驱动"还是"经济性驱动"，关键不是看有没有补贴，而是看**补贴退坡后需求是否还能增长**。2018年光伏行业通过了这个"压力测试"，标志着从政策驱动期进入过渡期的后半段。
- **结果**：光伏设备指数在2018年10月触底后至2020年7月累计上涨176.35%，隆基股份等实现了从技术路线选择（单晶）到产业链垂直整合的完整超额收益。

### 案例 2：工程机械从新增驱动到存量更新双轮驱动的转变

- **问题**：2015年后基建与房地产投资增速出现明显下滑，市场普遍认为工程机械行业将长期低迷。但2016年开始挖掘机销量却持续创新高，与宏观投资数据出现背离。如何理解这种"背离"？
- **方法论的使用**：用设备更新周期框架重新定位行业需求结构。工程机械设备寿命周期为8-10年，2008年"四万亿"期间大量销售的设备在2016年前后集中进入更新期。根据申万宏源的测算，更新需求占2016年以来设备销量的至少一半以上。这意味着行业已经从"纯新增需求驱动"（2008-2011年，销量与基建投资高度相关）切换到了"存量更新+新增需求"双轮驱动（2016年后，销量与投资增速的相关性下降）。同时，新的应用场景（农村小型机械、环保标准提升带来的提前更新、机器换人趋势）提供了增量弹性。
- **结论**：当一个耐用品行业出现"宏观投资增速下滑但销量创新高"时，应首先检查**设备更新周期是否进入集中更换窗口**，以及**是否有新的应用场景拓展**。这比简单的"基建不行了→工程机械不行了"的线性推理要准确得多。
- **结果**：2009-2015 下行期三一重工挖掘机市占率从 5%（2009.1）逆势提升至 18%（2015.12）；2016-2019 年行业迎来超预期的复苏行情，龙头率先修复估值，成为行业首个获得估值溢价的龙头主机厂。零部件企业恒立液压因同时受益行业复苏（beta）和国产主机厂份额提升（alpha），营收复合增速达75%。

## A2 — 触发场景 (Future Trigger)

### 用户会在什么情境下需要这个 skill？

1. **新兴产业分析**：用户在调研一个自己不熟悉的新兴行业（如2025年的AI应用层、人形机器人、合成生物学），想快速建立对行业所处阶段的判断，知道在这个阶段应该关注什么指标、警惕什么风险。

2. **行业拐点判断**：用户在跟踪一个已经发展多年的行业（如新能源汽车、光伏、半导体），想知道"行业是不是快到顶了"或者"是不是正在经历从成长期到成熟期的切换"，需要结构化的判断框架而不是凭感觉。

3. **跨行业比较**：用户同时关注多个行业，需要一套统一的框架来比较"哪个行业处于更好的投资阶段"，而不是用每个行业自己的话语体系分别分析。

4. **政策冲击评估**：行业政策发生重大变化（如补贴退坡、牌照调整、监管收紧），用户需要判断"这只是短期扰动还是改变了行业的发展阶段"。

5. **投资逻辑验证**：用户在构建一个行业的投资逻辑（如"买龙头"vs"买弹性"），需要先确认行业处于什么阶段以选择匹配的策略。

### 语言信号（用户的话里出现这些就应激活）

- "XX行业现在处于什么发展阶段？"
- "这个行业的未来会怎样？增长空间还有多大？"
- "应该关注这个行业的哪些核心指标？"
- "这个行业现在像不像当年的XX行业？"
- "现在投资XX行业应该买龙头还是买黑马？"
- "这个行业的渗透率到哪里了？天花板在哪？"
- "政策变化会对这个行业产生多大影响？"

### 与相邻 skill 的区分

- 与 `historical-stage-benchmarking` 的区别：本 skill 是**向前看**——用渗透率/增速/政策信号推断行业当前在哪一个阶段以及下一步会走向哪里；`historical-stage-benchmarking` 是**向后看**——在历史中寻找相似的行业/时期作为参照。两者互补：先用本 skill 定位阶段，再用对标系统找历史参照。
- 与 `capacity-cycle-positioning` 的区别：本 skill 覆盖行业的完整生命周期（包含导入期和成熟期），产能周期是其中一个子维度（主要适用于中后期的周期性和重资产行业）。
- 与 `policy-driver-assessment` 的区别：本 skill 将政策视为阶段切换的关键信号之一，而 `policy-driver-assessment` 专门深入分析政策传导机制和政策-经济交互关系。

## E — 可执行步骤 (Execution)

当 skill 被激活后，agent 应按以下步骤执行：

1. **收集阶段判断的基础数据**
   - 获取行业渗透率（如有明确定义）及其近3-5年的变化趋势
   - 获取行业增速（营收/销量/装机量等）及其变化方向
   - 梳理行业当前的关键政策环境（补贴/牌照/税收/准入等）
   - **完成标准**：至少获得了渗透率、增速、政策环境三个维度的基础信息，且来源可追溯

2. **三阶段定位**
   - 对照三阶段特征判断行业位置：
     - 政策驱动期特征：渗透率<5-10%，经济性未实现，政策是需求主要驱动力，企业盈利薄弱
     - 过渡期特征：渗透率10-50%，经济性在部分场景实现，政策名义退坡但有隐性支撑，行业内部分化
     - 经济性驱动期特征：渗透率>50%，内生需求为主，竞争格局稳定，龙头溢价
   - 如果行业属于耐用品（有明确设备寿命周期），额外检查：宏观投资增速与设备销量的相关性是否下降，更新需求占比是否持续提升
   - **完成标准**：给出明确的阶段判断（政策驱动期/过渡期前半段/过渡期后半段/经济性驱动期），并列出支持该判断的至少3条证据
   - **判停条件**：若渗透率无法明确定义（如纯服务业），跳到 B 段边界说明，告知用户本框架适用性有限并终止

3. **阶段匹配——输出该阶段的观测清单**
   - 根据判断的阶段，输出对应的观测指标清单：
     - 政策驱动期：渗透率变化斜率、政策信号（补贴/牌照边际变化）、技术成本下降速度、单位经济模型（UE）是否改善
     - 过渡期：渗透率是否突破15-20%临界区、补贴退坡后需求是否守住、龙头企业市占率变化、海外/新市场需求是否接棒
     - 经济性驱动期：行业集中度（CR5）、龙头市占率趋势、设备更新周期位置（如适用）、ROE稳定性、估值分位数
   - 同时列出该阶段对应的典型风险（政策驱动期：补贴退坡风险、技术路线被替代风险；过渡期：产能过剩风险、政策震荡风险；成熟期：增长天花板、被颠覆风险）
   - **完成标准**：输出至少5个该阶段应关注的核心指标和至少3个该阶段的典型风险

4. **市值驱动力诊断（可选，当用户关心投资时机时触发）**
   - 分析当前行业市值主要由"预期驱动"还是"盈利支撑"
   - 评估：政策边际变化（预期层）、竞争格局变化（预期层）、估值分位（预期层）、量/价/成本趋势（盈利层）
   - **完成标准**：明确判断当前市值定价以哪层为主，以及该定价结构在历史上是否可持续

## B — 边界 (Boundary)

### 不要在以下情况使用此 skill

- **没有明确渗透率指标的行业**：如纯服务业（咨询、广告）、定制化B2B服务等。这些行业缺乏可量化的渗透率数据，三阶段框架缺乏核心锚点。但仍可参考"增速换挡+集中度变化"的简化版本。

- **受行政垄断完全管制的行业**：如烟草专卖、军工（某些领域）、市政水务等。这些行业的需求和供给都由行政命令而非市场力量决定，"政策驱动→市场驱动"的切换逻辑不适用，因为可能永远不会切换。

- **处于技术路线争议期且没有主流共识的行业**：如早期量子计算、核聚变等。如果在"技术能不能走通"这个层次还没有共识，讨论"渗透率"和"阶段切换"是空中楼阁。此时应该关注的是技术可行性的验证节点而非渗透率指标。

- **事件驱动型的小众投机领域**：如某种短期炒作的主题概念（元宇宙土地、虚拟币矿机等）。这些领域缺乏持续的产业基本面支撑，三阶段框架需要的基本面数据不存在。

- **处于剧烈范式转换期的行业**：如被生成式AI从根本上改变商业模式的行业（客服外包、基础翻译等）。如果行业的"存在前提"本身在被动摇，用传统生命周期框架判断阶段可能给出完全错误的结论——行业可能不是"进入成熟期"而是"走向消亡"。

### 作者在书中警告的失败模式

- **把政策催化当作经济性驱动**：光伏行业2009年和2012年的两次崩溃证明，在行业尚未实现经济性之前，政策驱动的需求繁荣不可线性外推。判断标准：补贴退坡后需求是否还能增长？

- **刺激越大，透支越深，低谷越长**：工程机械行业2012-2015年的四年低谷是对"四万亿"时期零首付激进销售的代价。政策刺激人为提前透支了未来需求，刺激退出后的出清比预期漫长得多。

- **"下行期"转"上升期"需要双重确认**：工程机械行业案例显示，销量增速转正并不一定意味着复苏——必须宏观背景配合验证，否则可能是短暂的低基数反弹。

### 作者的盲点 / 时代局限

- 三阶段框架建立在"行业终将走向成熟/稳态"的假设上，但日本多个行业经历了"失去的30年"而不是走向稳态，美国很多行业经历了"创造性毁灭"。稳态未必是终局，更可能只是当前样本不足的假象。
- 全书数据截至2020年，尚未经历2022-2023年的AI大模型革命。AI可能从根本上改变了某些行业的"S曲线"形状——例如编程、翻译、客服等行业的生命周期可能被AI加速跳过了传统阶段。
- "渗透率"作为核心锚点，其有效性高度依赖于渗透率的定义方式。同一行业可以有完全不同的渗透率定义（如AI行业：按用户渗透率、按企业采购渗透率、按收入渗透率），选择不同的定义可能得出截然不同的阶段判断。

### 容易混淆的邻近方法论

- **S曲线/创新扩散理论**：教科书中的S曲线是平滑对称的，但书中22个行业复盘显示，真实世界的产业演化路径往往有跳跃（光伏跳过部分阶段）、停滞（工程机械2012-2015年）、倒退（煤炭行业在行政干预下的反复）。本框架的"三阶段+切换信号"比教科书式的S曲线更接近中国市场的实际。
