## 零、原书概要

### 0.1 基本信息

| 项目 | 内容 |
|------|------|
| **书名** | 致敬，我们的市场——中国股债、行业全景复盘 |
| **作者** | 上海申银万国证券研究所有限公司（主编），王胜（策略首席）、黄子函（高级分析师）统筹，百余位行业分析师参与 |
| **出版年** | 2021年（第1版） |
| **类型** | 卖方研究机构的系统性历史复盘——以"复盘"为核心方法，对2003—2020年中国股债市场及22个行业的全景式历史回顾 |

### 0.2 全书要解决的核心问题

申万宏源策略团队在后记中坦陈了三层问题：

1. **如何确保复盘的是历史真相而非后见之明？** — 解法：逐日整理约 4400 个交易日的大事件日历，用统一的策略方法论框架贯穿所有复盘，回归"常识"做跨期类比。

2. **即使真相还原了，如何避免幸存者偏差？** — 解法：不只复盘成功的行业和牛股，也复盘失败的行业和退市公司（如无锡尚德、LDK、雏鹰农牧）。

3. **即使历史已清晰，如何与当下比较？** — 解法：用"基本面趋势 + 流动性/估值 + 风险偏好 + 外部冲击 + 政策"的统一框架，在不同行业和不同时期之间建立可比较的坐标系。

> **一句话主旨**：以五力模型系统性复盘中国资本市场过去20年的运行规律，揭示不同产业生命周期阶段的股价驱动逻辑、行业格局演化路径和牛熊转换的触发机制，为投资者提供一部"市场时光机"。

### 0.3 核心分析框架：五力模型

全书所有行业的复盘都基于统一的定价分析框架：

```
┌─────────────────────────────────────────────────────┐
│                    行业市值 / 股价                      │
│                         ↑                            │
│  ┌──────────┬──────────┬──────────┬──────────┬──────┐ │
│  │ 基本面趋势 │ 流动性/估值│  风险偏好  │  外部冲击  │ 政策  │ │
│  │ (分子端)  │ (分母端)  │ (情绪面)  │ (三管道)  │(中国特有)│ │
│  ├──────────┼──────────┼──────────┼──────────┼──────┤ │
│  │ 盈利增速   │ 利率方向   │ 仓位/情绪  │ 全球商业周期 │ 货币政策 │ │
│  │ ROE趋势   │ 社融/信用  │ 增量资金   │ 美元/美联储  │ 产业政策 │ │
│  │ 营收增速   │ 估值分位   │ 市场叙事   │ 地缘政治    │ 监管力度 │ │
│  │ 毛利率     │ 外资流向   │ 换手率     │ 大宗商品    │ 财政刺激 │ │
│  └──────────┴──────────┴──────────┴──────────┴──────┘ │
│                                                       │
│  核心规律：                                              │
│  - 基本面趋势决定方向（中长期走势）                          │
│  - 流动性决定弹性（涨多快、跌多深）                          │
│  - 风险偏好决定波动（阶段性偏离基本面的幅度）                  │
│  - 外部冲击通过三管道传导（见 1.3 节）                       │
│  - 政策在中国市场的权重显著高于海外（见 1.1 节"政策与经济的交谊舞"）│
└─────────────────────────────────────────────────────┘
```

**不同时期的主导因子不同**：
- 牛市：三因子共振向上（基本面改善 + 流动性宽松 + 风险偏好上升）
- 熊市：三因子共振向下
- 震荡市：因子方向分歧

> 识别当前的主导因子是第一要务。比如 2014-2015 年是流动性主导（水牛），2016-2017 年是基本面主导（业绩牛），2018 年是风险偏好主导（去杠杆+贸易战双杀）。

### 0.4 关键术语表

本书有一系列特定术语，理解它们对于使用框架至关重要：

| 术语 | 定义 | 与常识用法的差异 |
|------|------|-----------------|
| **基本面趋势** | 企业盈利（ROE、净利润增速、营收增速）的方向和强度 | 不止是"好不好"，更强调"趋势是改善还是恶化"——二阶导比一阶导重要 |
| **水牛** | 缺乏盈利支撑、主要由流动性和风险偏好驱动的股价上涨 | 不是一般"牛市"，特指分母端驱动而分子端不配合，终将崩塌 |
| **业绩牛** | 由企业盈利改善驱动的股价上涨 | 有基本面支撑，更可持续。典型：2016-2017年 |
| **戴维斯双击** | 盈利增 + 估值升 = 乘数效应 | 在产业生命周期成长期更多双击，调整期更多双杀 |
| **戴维斯双杀** | 盈利降 + 估值降 = 乘数效应 | 触发条件见 4.2 节 |
| **脱敏** | 市场对反复冲击的反应逐渐减弱、开始走自身逻辑 | 不是"完全不受影响"，而是边际影响递减——判断底部/韧性的重要信号 |
| **反身性** | 股价下跌 → 质押平仓 → 更多抛售 → 加速下跌的自我强化 | 在A股特别强调特定机制（股权质押、两融平仓、止损线）触发 |
| **均值回归** | 资产价格、估值总有回归历史均值的引力 | 回归动力来自基本面趋势预期变化，而非统计规律 |
| **复盘** | 假设处在当时的市场环境，从逻辑出发决策，评估胜率和盈亏比 | 不是简单"回顾历史"，是可操作的决策训练方法 |
| **信号—驱动力验证** | 先识别市场信号（价格/估值/资金），再找基本面驱动力验证或证伪 | 区别于"先验逻辑"（先有基本面判断再预测市场），尊重市场信号的第一性 |
| **"像→不像→像"** | 历史类比的三个认知阶段：先找表面相似 → 识别关键差异 → 在驱动力层面回归共性 | 避免"这次完全一样"和"这次完全不一样"两个极端 |
| **万物皆周期 vs 穿越周期** | 中篇后记的哲学核心——短期所有行业受周期支配，但长期具备护城河的龙头可穿越 | 关键在于判断护城河深度和行业集中度的趋势，而非二选一 |

## 一、宏观背景：中国资本市场的底层驱动框架

### 1.1 "政策与经济的交谊舞" —— 最核心的宏观分析框架

申万研究所提出的核心理论框架：**政策与经济之间是一种类似"交谊舞"的互动关系，而非单向因果。**

```
经济下行 → 政策宽松 → 经济企稳 → 政策收紧 → 经济再下行 → ...
   ↑                                                       ↓
   └──────────────── 循环往复 ─────────────────────────────┘
```

**关键发现（来自上篇 A股年度复盘）：**

| 阶段 | 经济状态 | 政策取向 | 股市表现 | 典型案例 |
|------|----------|----------|----------|----------|
| **第一阶段** | 经济下行初期 | 开始宽松 | 触底反弹（估值修复） | 2008年末、2014年 |
| **第二阶段** | 经济企稳回升 | 维持宽松 | 主升浪（盈利驱动） | 2009H1、2016-2017 |
| **第三阶段** | 经济过热/通胀 | 转向收紧 | 见顶回落 | 2007H2、2010年末 |
| **第四阶段** | 经济加速下行 | 持续收紧 | 熊市主跌 | 2008年、2018年 |

**核心规律**：
- **政策底 → 估值底**（政策信号出现，预期先行）
- **估值底 → 市场底**（估值压缩到极端，卖压衰竭）
- **市场底 → 经济底**（股市领先经济约6-12个月）
- **经济底 → 业绩底**（企业盈利最迟见底）

### 1.2 流动性的三层结构

流动性不是单一概念，而是分层的：

```
第一层：央行流动性（基础货币、准备金率、公开市场操作）
   ↓ 传导
第二层：金融市场流动性（银行间利率、社融增速、信用利差）
   ↓ 传导
第三层：实体经济流动性（企业贷款、M1增速、企业活期存款）
```

**重要规律（来自债券复盘）**：
- "宽货币"不等于"宽信用"——2014-2015年央行多次降准降息，但信用传导不畅，股市表现分化
- **"紧信用"对股市的杀伤力大于"紧货币"**——2018年去杠杆加贸易战叠加，社融增速骤降，A股全年单边下跌
- 信用利差走阔是经济恶化的先行信号——2011年、2018年信用利差骤升均领先股市下跌

### 1.3 海外因素传导的三条渠道

```
渠道一：商业周期传导
  全球经济加速 → 中国出口增长 → 制造业盈利改善 → A股上涨

渠道二：美元流动性传导
  美联储宽松 → 全球流动性充裕 → 资金流入新兴市场 → A股受益

渠道三：政治周期共振
  中美关系恶化 → 风险偏好下降 → A股估值压缩
```

**关键判断（上篇原文）**："外因最终通过内因起作用"——当A股自身估值处于低位、基本面趋势向好时，外部冲击的影响有限；当A股处于高估值+基本面恶化时，外部因素才成为压垮骆驼的最后一根稻草。

## 二、行业生命周期：三种基本模式

通过对全书 22 个行业的分析，行业生命周期并非只有一种模式，而是**三大类**（周期制造型、技术迭代型、品牌消费型）：

### 2.1 模式一：周期制造型（典型"导入→成长→成熟→下行→出清→重生"）

**代表行业**：工程机械、煤炭、造纸、有色金属、油轮、建筑

```
            成长期          成熟期          下行期         出清期         重生期
            量价齐升      增速放缓      产能过剩      行业出清      龙头集中
    ┌─┐     /‾‾‾\                        ____
   /   \   /     \                      /    
  /     \─/       \────────────────────/      ───────
 导入期                                   
```

**各阶段驱动因素与信号**：

| 阶段 | 核心驱动 | 需求端信号 | 供给端信号 | 利润特征 | 典型年例 |
|------|----------|-----------|-----------|----------|----------|
| **导入期** | 技术引进/进口替代 | 渗透率<10% | 国产化率低 | 亏损或微利 | 工程机械2000年前 |
| **成长期** | 基建/地产投资高速增长 | 销量增速>20% | 产能扩张同步 | 量价齐升，利润率走高 | 工程机械2005-2010 |
| **成熟期** | 存量更新+出口 | 增速降至个位数 | 产能充裕 | 利润率稳定但增速放缓 | 工程机械2015年后 |
| **下行期** | 需求萎缩+产能过剩 | 销量负增长 | 产能大量闲置 | 全行业亏损或微利 | 煤炭2012-2015 |
| **出清期** | 政策倒逼/市场淘汰 | 需求企稳 | 小产能退出 | 龙头率先盈利 | 造纸2014-2015 |
| **重生期** | 供给侧改革/龙头集中 | 需求稳定 | 产能紧平衡 | 龙头利润创新高 | 煤炭2016年后 |

**关键规律**：
1. **"盈利领先制造业投资大约1年"**（造纸、煤炭、有色行业反复验证）——当年利润高→次年扩产意愿强→第三年产能投放→第四年供需恶化
2. **产能投放周期决定价格弹性**：铜矿（5-7年投产周期）、造纸（2-3年）、油轮（2-3年建船期）——供给刚性越强的行业，价格弹性越大
3. **"供给短期刚性，需求小幅变化引发价格剧烈波动"**（油轮行业核心规律）

### 2.2 模式二：技术迭代型（多轮"导入→爆发→成熟→衰退→新导入"小周期叠加）

**代表行业**：通信（1G→5G）、光伏（多晶→单晶→TOPCon→HJT）、医药（仿制药→创新药）

```
  技术代际A              技术代际B              技术代际C
   /‾‾‾\                 /‾‾‾\                 /‾‾‾
  /     \               /     \               /
 /       \_____________/       \_____________/
导入→爆发→成熟→衰退   导入→爆发→成熟→衰退   导入→爆发→...
```

**通信行业规律（5G复盘）**：

| 阶段 | 时间窗口 | 股价驱动 | 代表性事件 |
|------|----------|----------|-----------|
| 技术准备期 | 牌照前-3年至-1年 | 估值修复（预期驱动） | 3G/4G/5G标准冻结 |
| **牌照前后2年** | 牌照前-1至后+1 | **超额收益最显著** | 商用牌照发放 |
| 资本开支高峰期 | 牌照后1-3年 | 盈利大幅增长驱动 | 运营商大规模建网 |
| 资本开支下降期 | 牌照后3-5年 | 结构性机会 | 流量增长→光模块等 |
| 衰退期 | 下一代技术前 | 绝对/相对负收益 | 新技术预期出现 |

**光伏行业规律**：

三阶段演进路径：
```
政策驱动期 → 过渡期（平价上网） → 经济性驱动期
补贴政策是核心  LCOE持续下降       光伏+储能<火电
估值波动极大     估值+盈利共振       现金流为王
```

**关键信号**："度电成本下降是光伏行业发展主线，技术进步是推动降本增效主旋律"

### 2.3 模式三：品牌消费型（"高速增长→高质量增长"的驱动力切换）

**代表行业**：食品饮料、白酒、家电（白电）、医药（部分子行业；注：医药跨两类——仿制药/创新药偏技术迭代型，品牌中药偏品牌消费型，本表按主要属性归类）

```
       高速增长期              高质量增长期
   (2000-2012)              (2013至今)
   
   渠道扩张驱动              品牌+产品驱动
   /‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾‾\     
  /                    \     ——————————————（不会消失，格局优化）
 /                      \   
导入期                转折点（2013年）
```

**与周期制造型的关键差异**：

| 维度 | 周期制造型 | 品牌消费型 |
|------|-----------|-----------|
| 成熟后走向 | 下行→出清→重生 | 品牌分化→龙头恒强 |
| 衰落风险 | 产能可被永久淘汰 | 品牌不会消亡（可能衰落但可复兴） |
| 驱动力转换 | 需求→供给→集中度 | 渠道→品牌→管理效率 |
| 规模效应 | 有上限（管理半径） | 品牌效应可无限放大 |
| 典型估值 | 周期底部PB<1，顶部PE<10 | 稳定期PE 20-40x |

**食品饮料行业核心规律**：

"以产能和渠道驱动为主导的高速增长期（2000—2012年）和以品牌、渠道、品质为主导的高质量增长期（2013年至今）"

"复合提价能力提升的背后是品牌力的形成过程"——提价能力 = 品牌力 = 护城河深度

#### 2.3.1 消费行业分析的特殊框架："四力模型"

下篇前言指出，消费行业分析需要在传统的"产品力、品牌力、渠道力"三力基础上加入"创新力"：

```
           ┌─────────────────────────────┐
           │       消费行业"四力模型"       │
           ├───────────────┬─────────────┤
           │  产品力        │  品牌力       │
           │  (Product)     │  (Brand)     │
           │  品质/功能/成本  │  认知/溢价/忠诚 │
           ├───────────────┼─────────────┤
           │  渠道力        │  创新力       │
           │  (Channel)     │  (Innovation)│
           │  覆盖/效率/下沉  │  品类/模式/体验 │
           └───────────────┴─────────────┘
```

**四力在不同阶段的主导地位不同**：

| 阶段 | 主导力 | 代表案例 | 关键指标 |
|------|--------|---------|---------|
| 高速增长期（2000-2012） | **渠道力** > 产品力 | 纺服加盟扩张、家电渠道下沉 | 门店数量增速、经销商数量 |
| 品牌分化早期（2013-2016） | **品牌力** > 渠道力 | 白酒高端化、格力品牌溢价 | 提价频率和幅度、品牌认知度 |
| 高质量增长期（2017至今） | **创新力** > 品牌力+渠道力 | 安踏多品牌矩阵、海尔卡萨帝 | 新品类/新模式收入占比 |

**投资含义**：
- 消费行业从"渠道为王"→"品牌致胜"→"创新驱动"是不可逆的演进方向
- 当一个消费行业的主导力从渠道切换到品牌时，龙头集中度加速提升——这是估值中枢上移的起点（白酒2016、家电2014）
- 当一个消费行业的创新力超过品牌力时，行业格局可能被颠覆（"90后""00后"消费主力带来的需求碎片化）
- 下篇前言指出："20年表现最佳的前六个行业中有四个是消费品类——食品饮料(27.7倍)、休闲服务(11.3倍)、生物医药(11倍)、家电(6.8倍)"——但这一统计是时代的贝塔，需结合 5.5 节的"核心资产切换"审视

## 三、产业链利润传导规律

### 3.1 成本传导的一般性规律

```
上游资源（煤/矿/油）
    ↓ 价格上涨，利润向上游集中
中游制造（钢铁/水泥/组件/造纸）
    ↓ 能否传导取决于：（a）产能利用率（b）下游需求弹性（c）行业集中度
下游品牌/终端（消费品/建筑/电力）
    ↓ 能否消化取决于：（a）品牌提价能力（b）客户价格敏感度（c）替代品
消费者/用户
```

**规律总结**：

| 场景 | 上游 | 中游 | 下游 | 历史案例 |
|------|------|------|------|----------|
| **供给紧缺+需求旺盛** | 暴利 | 利润稳定 | 成本承压 | 2016-2018煤炭→火电 |
| **供给充裕+需求旺盛** | 利润稳定 | 暴利 | 利润改善 | 2014-2015光伏→电站 |
| **供给过剩+需求下行** | 亏损 | 亏损最大 | 获利（成本下降） | 2012-2015 煤价暴跌→火电暴利 |
| **供给出清+需求稳定** | 利润恢复 | 龙头暴利 | 利润压缩 | 2016年后造纸龙头 |
| **品牌提价+消费升级** | 影响有限 | 影响有限 | 品牌龙头暴利 | 2016-2020白酒 |

### 3.2 产能投资周期的跨行业规律

```
盈利增长 → 扩产意愿增强（滞后约1年）
         → 资本开支增加（滞后约2年）
         → 新产能投放（滞后约3-5年）
         → 供需恶化（滞后约4-6年）
         → 盈利下滑 → 减产 → 出清 → ...
```

**不同行业的产能投放周期**：

| 行业 | 投产周期 | 资金门槛 | 技术门槛 | 产能弹性 |
|------|----------|----------|----------|----------|
| 铜矿 | 5-7年 | 极高 | 高 | 极低 |
| 煤炭 | 3-5年 | 高 | 中 | 低 |
| 油轮 | 2-3年 | 高 | 低 | 低 |
| 造纸 | 2-3年 | 中 | 低 | 中 |
| 光伏组件 | 1-2年 | 中 | 中 | 高 |
| 通信设备 | <1年 | 低 | 高 | 高 |

**核心规律**：投产周期越长、资金门槛越高的行业，周期波动幅度越大；投产快的行业波动快但幅度小。

### 3.3 成本加成 → 品牌溢价的利益分配演变

```
2000年代：成本加成定价
├── 上游涨价 → 中游顺利传导 → 下游被动接受
├── 企业利润 = 产能规模 × 毛利率（稳定）
└── 投资关键：看产能扩张速度

2010年代：品牌溢价定价
├── 上游涨价 → 中游分化（龙头传导、小厂亏损）
├── 下游品牌：提价能力决定利润归属
└── 投资关键：看品牌力/定价权
```

## 四、股价涨跌规律：估值与盈利的切换

### 4.1 行业生命周期各阶段的股价驱动

| 生命周期阶段 | 股价主要驱动 | 估值特征 | 盈利特征 | 投资策略 |
|-------------|-------------|---------|---------|---------|
| **导入期** | 100% 估值（主题/概念） | PE极高或无盈利 | 亏损或极低 | 风险投资、主题博弈 |
| **成长早期** | 70% 估值 + 30% 盈利 | PE 40-80x | 增速50%+ | 赛道投资、选龙头 |
| **成长中期** | 50% 估值 + 50% 盈利 | PE 20-40x | 增速20-50% | PEG<1买入 |
| **成长晚期** | 30% 估值 + 70% 盈利 | PE 15-25x | 增速15-25% | 看盈利超预期 |
| **成熟期** | 100% 盈利（估值稳定） | PE 10-20x | 增速5-15% | DCF估值、看分红 |
| **下行早期** | 戴维斯双杀 | PE压缩+盈利下滑 | 增速转负 | 卖出/做空 |
| **下行晚期** | 估值修复预期 | PB<1, PE极高 | 全行业亏损 | 反向布局 |
| **出清/重生期** | 盈利弹性驱动 | PB修复 | 龙头利润暴增 | 买龙头反转 |

**规律来源**：
- 老板电器完整演绎："成长期PE 20-40倍（PEG<1），增速换挡后PE回落至15倍（PEG>1）"
- 煤炭："2016年前顺周期高beta，2016年后公用事业属性增强"
- 汽车："股价先于基本面变化，ROE相较指数变动存在滞后"
- 5G：3G/4G行情"超额收益主要来源于盈利大幅增长"，5G初期"超额收益主要来源于估值修复"

### 4.2 戴维斯双击/双杀的发生条件

**戴维斯双击（估值+盈利同时向上）**：
1. 行业从下行→出清的拐点（产能出清+需求企稳）
2. 技术迭代中的牌照/许可发放（通信3G/4G/5G牌照前后）
3. 消费行业品牌力形成后的提价周期（白酒2016-2020）

**戴维斯双杀（估值+盈利同时向下）**：
1. 销量增速二阶导转负（汽车行业铁律）
2. 需求断崖（白酒2012年"八项规定"+塑化剂）
3. 增速换挡（从高增长进入低增长，PEG从<1变为>1）
4. 库存危机+需求下滑（纺服2008年后）

### 4.3 底部和顶部的信号特征（综合多行业验证）

**底部信号体系**：

| 信号类型 | 具体指标 | 判断标准 |
|----------|----------|----------|
| **估值信号** | PB/PE历史分位 | PB<1x（周期股）、PE<历史10%分位 |
| **盈利信号** | 行业ROE | 全行业亏损或ROE<5%（持续2季度+） |
| **供给信号** | 中小产能退出 | 行业开工率<60%、小企业倒闭潮 |
| **债务信号** | 违约风险 | 煤企"债务负担过重，违约风险增大" |
| **政策信号** | 政策转向 | 从收紧→松绑/刺激 |
| **仓位信号** | 机构持仓 | 持仓比例降至历史极低 |
| **舆论信号** | 市场情绪 | "这个行业永远没有机会了" |

**顶部信号体系**：

| 信号类型 | 具体指标 | 判断标准 |
|----------|----------|----------|
| **估值信号** | PE/市值 | PE>历史80%分位、市值/GDP异常 |
| **供给信号** | 新增产能 | 大规模资本开支计划公布 |
| **需求信号** | 增速二阶导 | 销量增速从加速→减速 |
| **库存信号** | 渠道库存 | 库存周转天数连续上升 |
| **政策信号** | 政策收紧 | 加息/收紧信贷/去杠杆/调控 |
| **行为信号** | 新股发行 | 大量同行业公司IPO/再融资 |
| **舆论信号** | 市场情绪 | "这次不一样/永远涨" |

## 五、两大历史分水岭：2008年与2016年

### 5.1 全书反复验证的核心发现

> "平时工作繁忙甚少见面的分析师们总是不约而同地把2008年、2016年等年份作为行业重要阶段的分水岭……背后是显然宏观驱动力之间的共振。"（中篇后记）

### 5.2 2008年分水岭：从需求侧到政策侧

**2008年前的时代特征**：
- 中国经济高速增长（GDP增速>10%）
- 城镇化、工业化双重拉动
- 各行业处于渗透率快速提升阶段
- 股价由**需求侧逻辑**主导：谁产能扩张快谁就增长快

**2008年后的变化**：
- "四万亿"刺激改变了所有周期行业运行轨迹
- 政策成为比需求更重要的变量
- 海外因素（美联储QE）对A股影响显著增大
- 股价由**政策刺激逻辑**主导（2009-2015年）

### 5.3 2016年分水岭：从总量到结构

**2016年前的时代特征**：
- 经济增速下台阶但总量仍在扩张
- 各行业渗透率趋于见顶
- 同涨同跌的行业Beta行情

**2016年后的深刻变化**：

1. **"分化"成为最常见的关键词**：行业之间分化、企业之间分化
2. **供给侧逻辑取代需求侧逻辑**：行业集中度提升成为核心Alpha来源
3. **择时重要性下降**："择时对净值的边际贡献下降，周期行业研究员坐冷板凳的时间越来越长"
4. **龙头效应**：存量经济下龙头凭借品牌、成本、融资优势挤压中小企业
5. **产业政策影响力达到顶峰**：供给侧改革、房住不炒、集采、环保限产等

```
2008年前           2009-2015          2016年后
需求侧逻辑    →   政策刺激逻辑   →   供给侧逻辑
总量增长          逆周期调控          存量分化
行业普涨          政策主导波动        龙头Alpha
```

### 5.4 对各行业的差异化影响

| 行业类型 | 2016年前特征 | 2016年后变化 |
|----------|-------------|-------------|
| **煤炭** | 煤价与国际油价高度相关（70%） | 供给侧改革后相关性降至25%，公用事业属性增强 |
| **钢铁/造纸** | 产能过剩，价格战 | 环保清退+集中度提升，龙头利润创新高 |
| **房地产** | 高波动，金融属性强 | "房住不炒"后周期波动被熨平 |
| **银行** | 规模扩张驱动 | 资产质量改善驱动，基本面分化 |
| **白酒** | 三公消费驱动 | 大众消费承接，品牌分化加剧 |
| **家电** | 补贴+地产周期驱动 | 双寡头格局，利润稳定增长 |
| **医药** | 仿制药普涨 | 创新药vs仿制药剧烈分化 |

### 5.5 后记揭示的三层哲学命题

> 中篇后记"万物皆周期VS穿越周期"和下篇后记"唯有时代，盛开着永不凋零"是全书的哲学核心。以下三个命题贯穿全书，是理解所有行业规律的上层框架。

#### 命题一："分化"是2016年后最核心的行业关键词

> "在2016年之后，许多行业分析师都称存量经济下行业集中度提升带来alpha逻辑，因此部分公司能够'穿越周期'。'分化'——细分行业之间分化、大小企业之间分化——是笔者在行业复盘部分最常见到的词汇之一。"

"分化"不是某个行业的特有现象，而是2016年后**所有行业的共同特征**：

| 分化的维度 | 具体表现 | 在案例档案中的体现 |
|-----------|---------|------------------|
| **行业内大小企业分化** | 龙头集中度持续提升，小企业被挤压或出清 | 造纸：太阳纸业vs行业（Alpha 427% vs 指数52%）；工程机械：三一市占率5%→18% |
| **子行业之间分化** | 同一大行业内不同子赛道的命运截然不同 | 医药：创新药vs仿制药估值差3-5倍；汽车：整车强周期vs零部件穿越周期 |
| **A股与港股/美股之间分化** | 同一行业在不同市场的定价逻辑差异巨大 | 纺服：A股整体弱势vs港股安踏/李宁强势；电力：美股长牛vsA股大起大落 |
| **"核心资产"范畴频繁切换** | 2003→2021年"核心资产"的定义至少切换了四次 | 公用事业(2003)→钢铁石化(2006)→消费(2010)→消费龙头+周期龙头(2017)→？ |

**投资含义**：2016年后，**"买行业"不如"买龙头"**。择时对净值的边际贡献下降，选股的边际贡献上升。但这并不意味着择时不再重要——在行业出清→重生的拐点，择时仍然是决定胜负的关键。

#### 命题二："择时"与"选股"不是对立面

> "踏着周期之浪，同时实践无偏见的龙头公司比较，不同驱动力的股票用不同的打法，这是做投资最理想的状态。择时选手和选股专家一度被认为是'平行世界'，而这两者事实上并非站在对立面。"

这一命题将我们的两大类技能统一起来：

```
        择时维度                          选股维度
    ┌──────────────┐                ┌──────────────┐
    │ 判断行业在周期的  │                │ 判断龙头公司的   │
    │ 什么位置（底部/  │  ←── 互补 ──→ │ 护城河是否真实  │
    │ 顶部/中途）     │                │ 和可持续       │
    └──────┬───────┘                └──────┬───────┘
           │                               │
    ┌──────▼───────┐                ┌──────▼───────┐
    │ bull-bear-    │                │ leader-moat-  │
    │ signal-system │                │ assessment    │
    │ capacity-cycle│                │ 白酒/家电/通信  │
    │ -positioning  │                │ 案例验证       │
    └──────────────┘                └──────────────┘
           │                               │
           └───────────┬───────────────────┘
                       ▼
        "顺周期中的alpha"——在周期底部买龙头
        煤炭：陕西煤业（供给侧改革最大受益者）
        造纸：太阳纸业（行业低谷五年利润连增）
        工程机械：恒立液压（行业复苏+国产替代双驱动）
```

#### 命题三："没有核心资产的时代，只有时代的核心资产"

> "核心资产的确立是个结果，复盘核心资产或者非核心资产，都是为了从各个角度把握时代的脉络。错把趋势当永恒，必然会错失下个时代的机遇。"

**2003→2021年"核心资产"的四次切换**：

| 时期 | "核心资产"定义 | 代表行业 | 后来的结局 |
|------|---------------|---------|-----------|
| 2003-2004 | 公用事业垄断+大国企 | 港口/公路/钢铁/石化 | 2004年后公用事业再无板块性机会 |
| 2006-2007 | 城镇化+出口驱动周期股 | 钢铁/有色/煤炭/工程机械 | 2008年金融危机终结 |
| 2010-2015 | 消费+互联网 | 白酒/家电/医药/互联网 | 2015年互联网泡沫破灭；消费穿越了周期 |
| 2017-2021 | 各行业龙头（"茅台们"） | 消费龙头+周期龙头 | 2021年美债利率跳升→估值压缩 |

**规律**：
1. 每一次"核心资产"的确立都有坚实的基本面支撑（不是纯泡沫）
2. 但当市场叙事从"好公司"升级为"永续增长/永恒赛道"时，顶部往往不远
3. 被上一轮抛弃的行业，可能在下一轮以新的逻辑回归（如长江电力2004年见顶后2016年再度崛起）
4. **消费行业的"长牛"属性是时代赋予的，不是天然的**——美股近30年必需消费品跑不赢指数

**投资含义**：
- 当分析一个行业是否"值得长期持有"时，必须区分"时代的Beta"和"公司的Alpha"
- 验证"穿越周期"需要三个条件（见 7.3 节），缺一不可
- **消费不一定永恒**——案例档案中的农林牧渔和教育已经证明了这一点
- 在"核心资产"叙事最盛时保持警惕，在"这个行业永远没机会了"的绝望中寻找拐点

## 六、行业分析信号指标体系

### 6.1 判断行业所处生命周期阶段的指标框架

| 判断维度 | 导入期 | 成长期 | 成熟期 | 下行期 | 出清/重生期 |
|----------|--------|--------|--------|--------|------------|
| **渗透率** | <5% | 5-30% | 30-70% | >70% | 稳定 |
| **销量增速** | >100% | 20-100% | 0-20% | 负增长 | 0-5% |
| **行业集中度** | 分散 | 开始集中 | 寡头格局 | 淘汰中小 | 龙头份额提升 |
| **ROE水平** | 负或极低 | 15-30% | 10-20% | <5% | 龙头15%+ |
| **资本开支/折旧** | >2x | 1.5-2x | 1-1.5x | <1x | ≈1x |
| **企业数量** | 快速增加 | 大量进入 | 稳定 | 开始减少 | 显著减少 |
| **定价权** | 无 | 弱 | 龙头有 | 无（价格战） | 龙头强 |
| **政策态度** | 扶持 | 规范 | 中性 | 救助/退出 | 供给侧管理 |

### 6.2 产业链位置判断矩阵

```
                        上游
                      (资源/能源)
                     /           \
                    /   中游制造   \
                   /   (加工/组装)  \
                  /         |        \
                 /     下游品牌/服务   \
                /     (消费品/公用)     \

上游利润弹性指标：
  - 产能利用率 > 85% → 利润扩张
  - 库存天数连续下降 → 价格上涨信号
  - 资本开支大幅缩减 → 未来供给紧张

中游利润弹性指标：
  - 毛利率趋势（受上游+下游双重挤压程度）
  - 产能利用率（是否>80%）
  - 行业集中度（CR3是否>50%）

下游利润弹性指标：
  - 品牌定价权（提价频率和幅度）
  - 渠道库存周转天数
  - 市场份额变化趋势
```

### 6.3 股价底部/顶部的量化信号

**底部确认的增强信号（需要多项共振）**：

| # | 信号 | 权重 | 说明 |
|---|------|------|------|
| 1 | PB跌破1倍（周期股） | 高 | 行业被视为清算价值 |
| 2 | 至少2-3家龙头企业亏损 | 高 | 全行业亏损，产能出清在即 |
| 3 | 资本开支连续2年下降 | 高 | 未来供给收缩确定 |
| 4 | 政策信号出现拐点 | 高 | 收紧→宽松的关键转折 |
| 5 | 行业指数距高点跌>60% | 中 | 历史大底跌幅参考 |
| 6 | 机构持仓降至历史最低 | 中 | 筹码出清 |
| 7 | 媒体一片悲观 | 低 | 情绪见底（辅助验证） |

## 七、行业对比复盘操作框架

### 7.1 分析流程：五步法

```
第一步：定位行业类型
├── 周期制造型？→ 重点分析产能周期+供需缺口
├── 技术迭代型？→ 重点分析技术代际+渗透率阶段
└── 品牌消费型？→ 重点分析品牌力+渠道变迁

第二步：判断生命周期阶段
├── 用 6.1 指标体系打分
├── 找出最相似的历史行业案例
└── 确认当前处于该阶段的哪个位置（早期/中期/晚期）

第三步：产业链利润定位
├── 当前利润集中在产业链哪个环节？
├── 未来1-2年利润会向哪里移动？（参考3.1节传导规律）
└── 当前环节的产能周期还有多久？（参考3.2节投产周期表）

第四步：股价驱动因子分析
├── 当前是估值驱动还是盈利驱动？（参考4.1节）
├── 是否有戴维斯双击/双杀的触发条件？（参考4.2节）
├── 底部/顶部的信号出现了几个？（参考6.3节）
└── 权重打分：买入/持有/卖出信号强度

第五步：历史对比验证
├── 找到2-3个最相似的历史阶段
├── 对比关键指标的相似度和差异
├── 识别"这次不同的"因素
└── 形成基准情景+乐观/悲观偏差情景
```

### 7.3 "万物皆周期 vs 穿越周期"的辩证应用

从中篇后记的核心理念出发：

**当分析框架指向"周期"时（适用于80%的情况）**：
- 识别周期位置 > 选股
- 关注供需拐点 > 长期趋势
- 估值纪律 > 故事逻辑

**当分析框架指向"穿越周期"时（适用于20%的情况）**：
- 品牌护城河（白酒/调味品/中药老字号）
- 技术垄断（少数硬科技）
- 特许经营权（免税/稀缺牌照）
- 规模效应正循环（白电双寡头）

**验证"穿越周期"的三个条件**：
1. 行业 CR3 > 60%（格局已定）
2. 龙头连续5年以上 ROE > 20%（持续创造价值）
3. 历史上至少经历一次行业下行而盈利未负增长（验证韧性）
