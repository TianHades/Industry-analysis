# 行业案例档案模板

> 此文件定义了所有行业案例档案的统一格式。创建新案例时，复制此模板并填写各字段。

---

## 一、案例身份证

| 字段 | 值 |
|------|-----|
| **行业名称** | （中文全称） |
| **生命周期模式** | [ ] 周期制造型 [ ] 技术迭代型 [ ] 品牌消费型 |
| **二级分类** | （上游资源 / 中游制造 / 下游品牌 / 信息服务 / 金融服务 / 其他） |
| **本案例覆盖时间** | YYYY - YYYY |
| **关键价格/价值锚** | （该行业最重要的单一跟踪指标，如：秦皇岛5500大卡动力煤、茅台一批价、LME铜价） |
| **次要跟踪指标** | （2-3个辅助判断指标） |
| **产能周期长度** | （从投资决策到产能释放的典型年数，N/A 如不适用） |
| **在全书中的定位** | （一句话说明为什么这个案例对理解行业规律重要） |
| **最相关的对比案例** | （书中其他行业中最相似的案例名称，用于跨行业类比） |

## 二、完整时间线

> 用表格形式列出该行业从书中覆盖时间范围内的关键节点。每条记录包含：

| 时间 | 生命周期阶段 | 关键价格/锚 | 销量/需求指标 | 行业ROE | 龙头名称 | 龙头ROE | 行业PE(中位数) | 标志性事件 | 政策信号 | 书中原文引用 |
|------|-------------|------------|-------------|---------|---------|--------|--------------|-----------|---------|------------|
| YYYY-MM | 阶段名 | 数值 | 数值+YoY% | % | 公司名 | % | x倍 | 描述 | 政策方向 | "原文引用" |
| ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |

> 时间线应有 10-20 行，关键转折点周边应加密（密集到季度级别）。

## 三、关键转折点深度拆解

> 对 3-5 个最重要的转折点（顶部/底部/拐点），逐一深度分析：

### 转折点 #1：[名称]

| 字段 | 值 |
|------|-----|
| **发生时间** | YYYY-MM（精确到月/季度） |
| **转折类型** | [ ] 底部反转 [ ] 顶部拐点 [ ] 增速换挡 [ ] 政策冲击 |
| **前期趋势** | 距高点跌 ___% / 距低点涨 ___%（持续 ___ 个月） |
| **触发信号列表** | 列出从6.3信号体系中触发了哪些信号 |
| **信号触发先后顺序** | 1. ___ → 2. ___ → 3. ___（按时间排序） |
| **从首个信号到股价拐点的时滞** | ___ 个月 |
| **拐点确认后12个月涨幅/跌幅** | ±___% |
| **与框架预测的相符程度** | [ ] 完全符合 [ ] 基本符合 [ ] 部分偏离 [ ] 完全偏离 |
| **若偏离，原因分析** | （自由文本） |
| **当时容易误判的陷阱** | （当时投资者最容易犯什么错？） |
| **书中对此转折的核心论述** | "原文引用" |

## 四、可对比特征向量

> 此节是该案例与"当前行业"进行匹配对比时的标准输入。每个维度取案例处于关键阶段时的典型值。
>
> **单值规则（v3 标准化）**：每个维度只填一个基准值（维度 1 生命周期可记录"主阶段（阶段序列见备注）"）。存在两个时点/子行业差异时，基准值取主阶段，另一值写入备注（格式如"【阶段变体：2016年出清/重生】…"）；单值维度只能勾选一个选项，其余差异写入备注（"该维另标注：…"）。维护脚本：`tools/normalize_case_vectors.py`。

| 特征维度 | 本案例的典型值 | 备注说明 |
|----------|-------------|---------|
| **1. 生命周期阶段(8选1)** | 导入期/成长期/成熟期/下行早期/下行晚期/出清期/重生期/衰退期 | |
| **2. 产能周期位置** | 扩产中 / 收缩中 / 底部稳定 / 刚出清 | |
| **3. 行业集中度 CR3** | CR3≈___% | 严格 CR3 口径；仅有 CR5/CR10 时写"CR3 未获取（CRn=…）"；子行业差异写入备注（不放在值单元格） |
| **4. 需求量增速 YoY** | ___% | 趋势：加速 / 减速 / 稳定 / 负增长 |
| **5. 估值分位数(5年)** | ___%（PE/PB在5年历史中的分位） | |
| **6. 盈利趋势方向** | [ ] ↑上升 [ ] ↓下降 [ ] →平稳 | |
| **7. 政策敏感度** | [ ] 极高 [ ] 高 [ ] 中 [ ] 低 | |
| **8. 供给刚性程度** | [ ] 极高(>5年投产) [ ] 高(3-5年) [ ] 中(1-3年) [ ] 低(<1年) | |
| **9. 成本传导能力** | [ ] 强(定价权) [ ] 中(部分传导) [ ] 弱(价格接受者) | |
| **10. 周期性强度(1-10)** | ___/10 | 1=极稳定，10=极波动 |
| **11. 海外因素敏感度** | [ ] 极高 [ ] 高 [ ] 中 [ ] 低 | |
| **12. 2008年效应** | [ ] 重大拐点 [ ] 加速器 [ ] 短暂冲击后恢复 [ ] 影响有限 | |
| **13. 2016年效应** | [ ] 重大拐点(供给侧改革) [ ] 加速器 [ ] 影响有限 [ ] 不适用 | |
