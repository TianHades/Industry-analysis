## 一、这是什么？

这本书（申万研究所《致敬，我们的市场》，2021年出版，复盘数据截至2020年）系统复盘了 2003-2020 年间 A股几乎所有重要行业的历史走势。但这些案例数据埋在 50 万字的原文中，难以快速查找。

**本案例库把书中每个行业的"完整故事"整理出来**——时间线、价格数据、龙头业绩、转折点信号、规律总结。当你分析一个当前行业时，可以快速在这里找到最相似的历史参照。

### 案例文件 Frontmatter 系统

所有案例文件现均包含 YAML frontmatter，支持自动化匹配调用：

```yaml
---
name: coal-complete-case
description: 煤炭行业完整案例...
triggers: ["煤炭", "供给侧改革", "产能出清", ...]
lifecycle_model: 周期制造型
source_chapters: [part0018_split_005.txt]
verified: true
verified_date: 2026-06-15
related_cases:
  - slug: 造纸
    relation: composes-with
---
```

`triggers` 字段使案例可被对话系统自动匹配——用户提到 "煤价" 或 "供给侧改革" 时自动加载煤炭案例。

## 三、如何使用：三步法

### 第 1 步：确定当前行业属于哪种生命周期模式

用框架文档第 6.1 节的 8 项指标给当前行业打分：
- 渗透率、销量增速、行业集中度 → 判断生命周期阶段
- 核心驱动力是产能扩张、技术迭代、还是品牌渠道？ → 判断生命周期模式

### 第 2 步：到 7.2 节类比速查表或本目录找到最相似案例

框架文档 7.2 节已经按行业类型列出了常见场景的速查表。找到最匹配的 1-2 个历史案例后，打开该案例的完整档案。

### 第 3 步：用对比复盘模板逐项对比

参考三个对比示范的格式，填写七个部分（Part 0–6）：
- Part 0：当前行业速描
- Part 1：生命周期定位（8项指标打分）
- Part 2：最相似案例匹配（含相似度得分+关键差异）
- Part 3：关键指标逐项对比
- Part 4：信号触发检查
- Part 5：情景推演（基准/乐观/悲观）
- Part 6：投资结论

## 四、关键设计理念

### 为什么是"案例档案"而不是"总结"？

总结告诉你"煤炭行业下行期一般持续3-4年"——但当你面对当前行业时，你需要的不是这条结论，而是**煤炭2012-2015年具体发生了什么**：价格从854跌到354（跌了58%）、龙头企业债务违约风险增大、政策从观望到2016年初的供给改出台……这些具体数据才能让你对照当前的行业。

### "可对比特征向量"是做什么的？

每个案例档案的第四节，都是一个标准化的 14 维特征向量。它的作用：
- **当你在分析当前行业时**，先给当前行业也填一份这14个维度的值
- **然后与历史案例的特征向量对比**，找出最相似的
- **相似度越高，历史案例的后续走势参考价值越大**

> **标准化规则（2026-10 起）**：14 维均为**单值基准**；多时点/子行业差异写入备注（"【阶段变体：…】"），单值维度只勾选一个选项（其余写入"该维另标注"）。维护：`python tools/normalize_case_vectors.py --apply --single-select`（结构性调整）与 `python tools/check_case_relations.py`（关系一致性/关系图生成）。

### "跨类型类比"原则

同生命周期模式内的类比最直接，但最有价值的洞察往往来自跨类型类比：
- 消费行业的"需求断崖"逻辑，可以类比周期行业的"产能过剩"——本质上都是供给过剩
- 技术迭代型行业的"牌照窗口"，可以类比消费行业的"品牌力确认"——都是某种"护城河确立"的信号
