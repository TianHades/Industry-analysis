# 农林牧渔行业案例档案

> 行业生命周期模式：周期制造型 | 二级分类：上游资源 / 下游消费（复合属性）

## 三、关键转折点深度拆解

### 转折点 #1：2018年8月——非洲猪瘟爆发（外部冲击型超级去产能）

| 字段 | 值 |
|------|-----|
| **发生时间** | 2018年8月（沈阳确诊首例非洲猪瘟）至2019年Q1（全国蔓延完成） |
| **转折类型** | [x] 底部反转 [ ] 顶部拐点 [ ] 增速换挡 [x] 政策冲击 |
| **前期趋势** | 猪价在2016Q3-2018Q1经历环保禁养驱动的超级猪周期上行（15-21元/kg），2018Q2猪价回落至10-15元/kg区间（周期正常下行）。彼时市场普遍预期猪价将继续走弱。 |
| **触发信号列表** | 1) 2018年8月3日沈阳确诊中国首例非洲猪瘟；2) 非洲猪瘟从北向南以不可控速度蔓延；3) 疫区生猪被大量扑杀（累计扑杀超百万头）；4) 跨省禁运政策实施，生猪调运体系瘫痪；5) 疫区养殖户恐慌性抛售→非疫区压栏；6) 能繁母猪存栏同比降幅从-2%急剧扩大至-20%→-30%→-40% |
| **信号触发先后顺序** | 1. 首例确诊（2018年8月）→ 2. 疫区扩散+扑杀（2018年9-11月）→ 3. 能繁母猪存栏数据连续大幅下滑（2018年10月起）→ 4. 疫区恐慌抛售导致猪价短期下跌（2018Q4）→ 5. 抛售结束、供给缺口暴露→ 6. 猪价暴涨（2019年3月起）→ 7. 股价领先猪价启动（2019年初即可观察到股价底部反转） |

| **拐点确认后12个月涨幅/跌幅** | 猪价从约10元/kg升至约42元/kg（涨幅约300%），牧原股份股价涨幅超过500% |
| **与框架预测的相符程度** | [ ] 完全符合 [ ] 基本符合 [x] 部分偏离 [ ] 完全偏离 |
| **若偏离，原因分析** | 框架预测了疫病驱动猪周期上行的经典逻辑（疫病导致供给收缩→猪价上涨），这与2006年蓝耳病一致。偏离之处在于：非洲猪瘟造成的去产能幅度远超历史上任何一次疫病，且因为非洲猪瘟无疫苗、致死率100%，产能恢复的速度远慢于历史任何一轮周期。这导致了"超级猪周期"——猪价高位持续时间、价格峰值、龙头企业盈利能力均创造了中国养猪史上前所未有的水平。标准的3-4年猪周期框架被这一"黑天鹅"完全改写。 |
| **当时容易误判的陷阱** | 陷阱一：初期低估疫情。2018年8-10月，大部分投资者将非洲猪瘟视为"局部可控事件"，认为政府会快速扑灭。实际上非洲猪瘟在中国的扩散速度和范围远超预期。陷阱二：将疫区恐慌抛售期的猪价下跌（2018Q4猪价跌至约10元/kg）误判为"猪周期继续下行"，看不清猪价下跌背后是"抛售→透支未来供给→未来更大的供给缺口"的逻辑。陷阱三：在高位"抄作业"。2019年底至2020年初，猪价已升至35-40元/kg，许多投资者看到暴利数据而追高买入，但此时供给已经开始恢复，最肥美的阶段已经过去了。 |
| **书中对此转折的核心论述** | "非洲猪瘟疫情爆发，生猪养殖规模急剧减少，生猪价格上涨预期愈发强烈" |

## 四、可对比特征向量

> 以养殖子行业（生猪）处于关键阶段时的典型值为准，同时在各维度备注中说明子行业间的差异。

| 特征维度 | 本案例的典型值 | 备注说明 |
|----------|-------------|---------|
| **1. 生命周期阶段(8选1)** | 永续周期性波动——出清期与下行期交替循环 | 养殖行业不存在传统意义上的"成长期→成熟期→衰退期"线性演进。它在"暴利期（猪价高位）→下行期（猪价下跌+亏损）→出清期（去产能）→暴利期"中永续循环。这是一种"不在任何标准生命周期阶段中停驻"的独特存在。相比之下，饲料子行业（海大集团代表）处于成熟期+集中度提升阶段，宠物食品子行业（中宠股份代表）处于成长期，种子子行业处于导入期（转基因商业化破冰）。 |
| **2. 产能周期位置** | 进入下行期后——去产能中（但深度和速度因"资产负债表厚度"而变慢） | 传统猪周期中，散户主导的去产能通常在12-18个月内完成。但2021-2024年的去产能被显著拉长，因为经历了2020年暴利的规模化企业资产负债表厚实，能够"以亏损换市场份额"。这是一个新变量——"资产负债表越厚，去产能越慢，底部越漫长"。 |
| **3. 行业集中度 CR3** | 约10-15%（2018年前，极度分散）→ 约20-25%（2023年，仍在加速集中） | 趋势：集中中。非洲猪瘟+环保禁养+猪价大波动三重压力加速了散户退出，牧原/温氏/新希望等龙头的出栏份额持续攀升。但与美国CR3约50%相比仍有巨大差距，"大行业小公司"格局正在被打破但远未完成。 |
| **4. 需求量增速 YoY** | 约0-2%（低速稳定） | 趋势：稳定/微幅负增长。中国猪肉消费总量已基本达峰（人均消费约40kg/年），长期趋势是缓慢下降（人口老龄化+饮食多元化）。需求端不是行业分析的核心变量，供给端才是。这一点与煤炭行业高度相似。 |
| **5. 估值分位数(5年)** | 极不稳定——暴利期PE约3-8倍（5年历史1-10%分位，极低）；亏损期PE被动极高/无法计算（5年历史90-100%+分位） | 养殖行业PE分位数是完全的"反向指标"——低PE意味着高盈利、高股价、周期顶部，应该卖出；高PE/无法计算PE意味着亏损、低股价、周期底部，应该考虑买入（但前提是确认去产能已充分）。正常年份用PE估值，底部年份看PB（<1倍为历史底部区域）、头均市值、猪价预期。 |
| **6. 盈利趋势方向** | [x] ↑上升（暴利期，如2019-2020） / [x] ↓下降（下行期，如2021-2023） / [ ] →平稳 | 农林牧渔（尤其是养殖子行业）的盈利不存在"平稳"状态——要么暴利，要么巨亏，两者之间的过渡期极短（3-6个月）。这种"二元极端化"盈利特征是周期型行业中最极端的，甚至比煤炭更极端。饲料子行业和宠物食品子行业则相对平稳，不具备此特征。 |
| **7. 政策敏感度** | [x] 极高 [ ] 高 [ ] 中 [ ] 低 | 养殖行业对政策高度敏感，且政策方向多变：环保禁养（去产能）→ 复养鼓励（补产能）→ 收储托底（抗跌）→ 进口调节（平抑价格）。转基因政策对种子子行业具有决定性影响（转基因商业化=种子行业从"主题"到"成长"的质变点）。 |
| **8. 供给刚性程度** | [ ] 极高(>5年投产) [ ] 高(3-5年) [x] 中(1-3年) [x] 低(<1年)——取决于规模 | 散户的供给弹性极高（6-8个月可完成补栏到出栏），规模化猪企的产能周期约10-18个月（母猪补栏到商品猪出栏约需10-12个月+猪场建设周期）。生物资产特有的"不可存储性"（猪养大必须出栏，无法像煤一样放在那里等涨价）使供给在价格下行期反而"越跌越多"——养殖户越亏越卖，形成价格下跌的正反馈螺旋。这是养殖比煤炭更惨烈的核心原因。 |
| **9. 成本传导能力** | [ ] 强(定价权) [ ] 中(部分传导) [x] 弱(价格接受者) | 猪肉是完全同质化的大宗商品，没有任何一家养殖企业的猪能卖得比市场价更高。即使是成本最低的牧原股份，也只能"低成本创造超额利润"而无法"定价"。当全行业每头亏损300-500元时，没有企业能幸免（成本最低的也只是少亏）。品牌肉（壹号土猪等）是极少数的例外但规模极小。 |
| **10. 周期性强度(1-10)** | 养殖：10/10（极致波动）。饲料：6/10。宠物食品：3/10。种子：7/10（政策驱动型波动） | 养殖子行业是A股所有行业中周期性最强的板块之一，甚至超过煤炭（9/10）。猪价从10元/kg到40元/kg到10元/kg的波动区间达4倍（煤价约3倍）。且波动频率更高（猪周期平均3-4年一轮完整周期 vs 煤炭5-8年）。宠物食品因消费属性强波动最低；饲料因成本加成定价模式波动居中；种子受政策影响大。 |
| **11. 海外因素敏感度** | [ ] 极高 [x] 高 [ ] 中 [ ] 低 | 中国猪肉自给率约95%+，进口占比低（约2-5%），所以海外猪肉价格对国内的绝对影响有限。但海外因素通过两条路径传导：1) 饲料原料（大豆、玉米）高度依赖进口（大豆进口依赖度约85%），海外农产品价格直接影响国内养殖成本；2) 非洲猪瘟等跨国动物疫病的传入风险。所以标记为"高"而非"极高"。 |
| **12. 2008年效应** | [ ] 重大拐点 [ ] 加速器 [x] 短暂冲击后恢复 [ ] 影响有限 | 2008年全球金融危机通过需求面（消费下降）加剧了当时猪周期的下行速度，但并非拐点本身。猪价在2008年从约17元/kg跌至约9元/kg，金融危机是"加速器"而非"根本原因"——根本原因仍然是猪周期自身的供给过剩。此后2010年猪价在疫病驱动下迅速回升至20元/kg，证明了外部冲击没有改变猪周期的内生运行逻辑。 |
| **13. 2016年效应** | [ ] 重大拐点(供给侧改革) [x] 加速器 [ ] 影响有限 [ ] 不适用 | 2016年的环保禁养政策对养殖行业的影响类似于煤炭的供给侧改革——通过行政力量加速了散户的去产能。但与煤炭不同的是：养殖行业的去产能是"部分不可逆"的（散户退出后不再回来），且政策后来又"反转"鼓励复产，形成了"政策先收紧再放松"的摇摆。因此它不像煤炭的供给侧改革那样彻底改变了行业属性，更多的是"加速器"角色。 |
| **14. Beta特征** | [x] 顺周期高Beta [ ] 顺周期低Beta [ ] 逆周期 [ ] 穿越周期 | 养殖子行业是典型的顺周期高Beta品种——猪价涨→盈利暴增→股价暴涨→更多资本进入；猪价跌→全行业亏损→股价暴跌→产能出清。且Beta值大于1——猪价涨幅和股价涨幅之间存在杠杆效应（股价涨幅通常远超猪价涨幅，反之亦然）。饲料子行业的Beta低于养殖；宠物食品子行业具有一定的"穿越周期"特征（与宏观经济弱相关+消费属性）。 |

## 五、规律总结

### 5.1 该行业验证的核心规律

1. **规律一：猪周期是"生物产能周期"的行为金融学表达——周期永远不会消失，只会变换节奏**
   - 具体表现：猪周期的底层驱动力是人类逐利本性的集体行为——猪价高时所有人都想养猪，猪价低时所有人都想退出。这一行为模式在没有外部强力干预（如配额制）的情况下永远不会改变。从2006年蓝耳病到2018年非洲猪瘟再到2021-2024年的深度去产能，每一轮猪周期的具体触发因素不同（疫病、环保政策、资本涌入），但"猪价暴涨→全行业扩产→供过于求→猪价暴跌→产能出清→猪价暴涨"的底层逻辑从未改变。即使在规模化程度显著提升的2020年代，规模化猪企的"集体行为"只是把散户的"蜂群效应"放大成了更加巨额的资本涌入和更漫长的去产能过程。
   - 案例作者概括：猪价暴涨→全行业扩产→供过于求→猪价暴跌，这一规律从未改变

2. **规律二："农林牧渔板块相对市场几乎没有超额收益"——这不是意外，而是行业内生属性决定的**
   - 具体表现：中国A股农业板块长期走势弱于大盘，书中确认了"几乎没有超额收益"这一扎心结论。原因有三：第一，养殖行业呈现"暴利→巨亏→暴利→巨亏"的零和甚至负和特征，长期平均ROE并不高（扣除极少数龙头，行业整体ROE在10%以下）；第二，生物资产的不可控因素（疫病、天气）频繁造成不可预期的毁灭性亏损；第三，"大行业小公司"格局下多数上市公司并不代表行业的优质产能，大量劣质上市公司拉低了板块整体表现。书中明确提到"相当部分公司弃农而去"——优质的农业公司往往选择转型其他行业，留下来的往往是"跑不掉"的。
   - 书中原文："农业板块相对市场几乎没有超额收益"、"早期优质农业上市公司相对较少，主营业务普遍缺乏成长性，业绩稳定性弱"、"相当部分公司'弃农而去'"

3. **规律三：子行业之间的差异大到无法用统一的"农林牧渔"框架分析——必须拆开看**
   - 具体表现：养殖（周期型）、饲料（后周期成长型）、宠物食品（品牌消费型）、种子（政策主题型）四个主要子行业的分析框架完全不同。将它们归入同一个"农林牧渔"行业指数是最容易犯的认知错误。养殖看猪价+能繁母猪，饲料看养殖存栏量（养殖后周期逻辑），宠物食品看品牌力+渠道+海外收入，种子看转基因政策进度。在一个统一行业分类标签下，这四个子行业经常出现完全相反的走势（如养殖暴跌时饲料可能受益于存栏高）。
   - 书中原文：农业投资将逐步"由'主题、周期'向'成长、消费'转型"

4. **规律四：生猪的"不可存储性"使猪周期比煤炭/钢铁等"可存储大宗商品"周期更惨烈**
   - 具体表现：煤矿可以在价格低时"停产保价"，钢铁可以在价格低时"检修减产"，但猪养大了必须出栏——不管猪价多低，猪不能"存着等涨价"。这导致了生猪供给的价格弹性极低甚至为负——当猪价暴跌时，养殖户为了减少每日饲料消耗的亏损，反而"越跌越卖"，形成了价格下跌→加速出栏→供给增加→价格进一步下跌的正反馈死亡螺旋。这是养殖行业在周期底部比煤炭更惨烈的根本原因。相比之下，煤炭在2014-2015年下行期，部分煤矿选择停产限产，一定程度上缓解了供需失衡的加剧。
   - 案例作者概括：通过猪价从高位跌至低位的极端案例间接验证——从暴利到巨亏只需半年，体现了生猪不可存储性的加速效应

5. **规律五：猪周期底部判断的核心信号不是"亏损"，而是"亏损的不可持续"——即去产能的彻底程度**
   - 具体表现：养殖行业在周期下行期始终处于亏损状态，但"亏多久才会真正出清"取决于行业资产负债表的厚度。2014年的底部，散户主导，资产负债表脆弱，亏损1-2年即大面积退出。2021-2023年，头部猪企资产负债表厚（经历过2020年暴利），亏损3年仍能"扛得住"，导致底部被显著拉长。核心指标应该是能繁母猪存栏的去化幅度（通常需要去化10-15%以上才算充分）和去化的"不可逆性"（散户退出不可逆，规模化企业产能关停可逆——猪场可以随时复产）。只看到亏损就抄底，大概率抄在半山腰。
   - 案例作者概括：人人都知道猪周期，但抄底抄在半山腰的人太多了

### 5.2 该行业出现的例外/意外

- **例外情况1：非洲猪瘟（2018-2019）——创造了一个"不可能的暴利窗口"**
  这是一种"外部黑天鹅"创造的极端情境，不适用于标准的"猪周期底部投资"框架。非洲猪瘟导致的产能急剧减少创造了养殖企业前所未有的暴利（牧原ROE达到极高水平），但其前提是"不可预知的超级疫病+无疫苗+致死率100%"——这不是可复制的投资机会，而是幸存者偏差。如果一个投资者试图"等下一个非洲猪瘟"来赚钱，那是在等一个发生概率极低、且一旦发生在自己持仓的企业上可能就是"归零"的事件。

- **例外情况2：牧原股份的"α远超行业β"**
  在大多数周期行业中，龙头的表现大致跟随行业Beta（如中国神华vs煤炭行业指数，方向一致，幅度差异有限）。但牧原股份在2015-2021年间创造出了远超行业平均回报的α——自繁自养模式的成本优势（比行业平均低2-4元/kg），使其在行业暴利时赚得更多、在行业亏损时亏得更少甚至不亏。这种"行业亏损我盈利"的结构性优势在周期行业中极其罕见，表明在极端优秀的α面前，周期的β框架可能低估了个股的潜力。但这也是"幸存者偏差"——如果只看到牧原而忽视了大量"弃农而去"和退市的劣质农业公司，就会误以为农林牧渔是"容易选出牛股"的行业。

- **例外情况3：环保禁养与"鼓励复产"的政策反转——政策从"做减法"变成"做加法"**
  2015-2016年环保禁养是去产能的"加法器"，使猪周期底部反转彻底而持久。但2019-2020年非瘟之后的政策180度转向"鼓励复产+放宽环保限制"，政策的"钟摆效应"使得套用历史模式失效——如果投资者在2021年后继续套用"环保禁养使供给恢复慢"的逻辑看多猪价，就会在2021年猪价断崖下跌中遭受重创。政策方向的反转是周期分析中容易被忽视的变量。

- **例外情况4：宠物食品子行业的"穿越周期"属性**
  农林牧渔行业中有一个子行业完全不适用于猪周期框架——宠物食品（中宠股份、乖宝宠物等）。宠物食品是品牌消费品，具有消费者品牌忠诚度、稳定的复购率、海外出口+国内消费升级双重驱动。它的走势更接近食品饮料行业而非养殖行业。在养殖子行业全线亏损的2022-2023年，宠物食品子行业整体实现了增长。这说明"农林牧渔"这个行业分类标签过于宽泛，内部子行业的逻辑差异大到不能在一个框架下分析。

### 5.3 该行业中容易误判的陷阱

- **陷阱1（最致命）：将"猪价反弹"误判为"猪周期反转"——"抄底抄在半山腰"的根源**
  在每一轮猪周期下行期中，猪价都会出现2-3次技术性反弹（幅度可达20-30%甚至更多，如2022年Q3反弹幅度达155%）。这些反弹往往伴随市场广泛宣告"猪周期反转"，引发大批投资者入场。但真正的底部反转需要满足一个核心条件——能繁母猪存栏实现了充分的、不可逆的去化。在这个条件达成之前，任何反弹都只是反弹。判断标准：能繁母猪存栏是否已经从前期高点下降了10-15%以上？去产能的主体是否以永久退出为主（散户关闭猪场）而非"暂时减产"（规模化企业降低存栏密度）？

- **陷阱2（最经典）：将"低PE"误判为"便宜"——周期股的PE反向指标特征在农林牧渔中更致命**
  在猪价暴利期（如2020年），龙头养殖企业PE仅3-6倍，看起来是整个A股最"便宜"的板块。但这不是安全边际——低PE意味着盈利处于不可持续的顶点，未来盈利将断崖式下降。在猪价底部亏损期，PE因盈利塌陷而被动极高甚至无法计算，这才是"便宜"的时候。周期股应该在"PE高时买入、PE低时卖出"。农林牧渔甚至比煤炭更难——生物资产的不可控因素可能使底部亏损期的"高PE"持��时间远超预期。

- **陷阱3：将"行业集中度必然提升"逻辑直接等同于"龙头永远受益"**
  逻辑本身是对的——非洲猪瘟+环保禁养+猪价波动确实在加速行业集中度提升。但集中度提升的过程对龙头股投资者可能是痛苦的——在猪价下行期，即使是牧原股份这样的成本优势龙头，股价也会跟随猪价大幅下跌（只是跌幅小于行业）。"集中度提升"是一个5-10年级别的长期趋势，不能用来论证"现在买入龙头就安全"。

- **陷阱4：将"规模扩张"等同于"成长"——错误地将周期性行业的产能扩张理解为消费行业的"成长"**
  在猪价高位期（如2020年），养殖企业纷纷宣布宏大的产能扩张计划（"未来三年出栏量翻倍"），许多投资者将其理解为"成长股"的投资逻辑，给予高估值。但在猪价下行期（2021-2023年），这些产能扩张计划变成了增加亏损的源头——养得越多亏得越多。"产能扩张"在周期行业中是周期上行的结果，而非"成长"的证明。真正的"成长"是穿越多轮周期的成本优势+效率提升（如牧原），而非在暴利期宣称的扩产计划。

- **陷阱5：忽视子行业之间的"负相关"关系——用养殖的分析去套饲料/种子/宠物**
  饲料是养殖的"后周期"行业——养殖存栏量高→饲料需求大→饲料企业盈利好。在养殖企业因为猪价低位而亏损时（存栏高、猪价低），饲料企业反而可能因为高存栏而盈利良好。用养殖的分析框架（看猪价）去判断饲料行业的景气度，会得出完全相反的结论。这是最基础但最容易被忽略的行业分析陷阱。

### 5.4 该案例对分析当前行业的启示

- **何时应该参考此案例**：
  1. **判断周期性行业的底部信号时**：农林牧渔（尤其是养殖）是研究"底部反转信号"最好的案例之一。当分析一个行业时，如果该行业符合"亏损→去产能→去产能充分→价格反转"的逻辑，应重点参考猪周期的底部判断方法论——关注去产能的充分性而非亏损的深度，关注"亏损的不可持续"而非"亏了多少"。
  2. **分析其他生物周期类行业时**：水产养殖、禽类养殖等其他生物资产相关行业，可直接类比猪周期的分析框架（产能周期、疫病冲击、不可存储性）。
  3. **当研究一个"长期跑输大盘"的行业是否值得投资时**：此案例是最直接的警示——如果一个行业存在"生物资产不可控"+"产品无法存储"+"行业集中度极低"+"长期ROE不高"的组合特征，即使有周期性的暴利窗口，长期持有的回报也很可能跑输大盘。此案例告诉投资者，战略性地回避某些行业是完全合理的选择。
  4. **当其他周期性行业出现"资产负债表变厚→去产能变慢"的新特征时**：2021-2024年猪周期去产能被拉长的经验，对未来分析任何"经历过暴利期之后的周期行业去产能"都具有参考价值。

- **此案例不能直接套用的情况**：
  1. **分析品牌消费品行业时**（白酒、调味品、乳制品等）：猪周期的"价格接受者+周期驱动"框架完全不可套用。品牌消费品壁垒来自消费者心智和品牌溢价，定价权来自品牌而非供需缺口。应参考白酒案例。
  2. **分析技术迭代型行业时**（面板、光伏、半导体）：猪周期的"供给产能周期"在技术迭代型行业中可能被"技术进步淘汰旧产能"的逻辑替代。应参考面板或光伏案例。
  3. **分析能"存储"的大宗商品时**（煤炭、石油、有色金属）：猪周期的"不可存储性加速下跌"特征不适用于可存储大宗商品。但"产能周期+价格波动"的逻辑是同构的。应参考煤炭案例。
  4. **当子行业差异极大时**：农林牧渔本身的子行业差异告诉我们，如果一个统一的行业分类标签下包含了完全不同的商业模式，必须按子行业分开分析。不能因为"都在一个GICS分类下"就使用统一框架。
  5. **当去产能已经被行政力量强制完成时**（如2016年后的煤炭）：如果当前行业的产能出清已经像煤炭一样被行政力量完成，则不应套用猪周期"等待市场自发出清"的框架——市场自发出清的时间可能长得无法忍受，而政策驱动的出清可以在短期内完成。
  6. **分析处于"成长"阶段的行业时**：宠物食品子行业的案例提醒我们，农林牧渔内部也存在成长型子行业。如果分析的行业处于渗透率提升、消费升级驱动的成长期，不应套用猪周期的周期框架。
